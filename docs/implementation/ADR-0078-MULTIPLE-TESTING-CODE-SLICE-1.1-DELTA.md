## Context

Envelope 10 produced zero false accusations and zero Findings but zero of six first-contact
positive candidates. The accepted recall recon localized seven source idioms and two misleading
abstention labels. Adversarial review then closed the mutable-flat-sequence hole, deferred the only
proposed hierarchy subtraction, and replaced an over-refusing escape rule with a finite read-only
consumer grammar. The final ND-2 clause closes list/tuple display leaves in fresh concatenations to
A1 scalar constants or names resolved to those scalars.

## Decision

1. Add check, adapter, and detector version `1.1.0` under the existing stable semantic IDs and move
   only the development binding to them. The 1.0 components remain immutable historical modules.
2. Copy the 1.0 multiple-testing dataflow, adapter, detector, and integration overlay into new 1.1
   modules. Implement only design admissions A1-A7, the whole-module immutable-sequence proof and
   closed read-only consumers, and the two honest abstention relabels.
3. The correction-terminal census, off-grammar transform guard, row-completeness equality,
   correction registries, threshold/product rule, local `.pvalue` requirement, and every resampling
   guard retain their 1.0 semantics. `_hierarchy_guard` is byte-identical and has no ternary carve-out.
4. A4 resolves only an authorized reader path formal; it creates no call-site frame. A5 requires one
   binding anywhere in the parsed module. A7 admits only the exact contract group-column equality
   and does not expose the non-group `_mask_rows` branch to bare boolean subscripts.
5. The Finding wording profile and scientific-requirement contract profile `1.2.0` are reused
   byte-for-byte. No wording v2, schema change, new semantic role, grant, pin, or qualification is
   authorized.
6. Code, CSV values, and closed API identities remain the only evidence channels. Prose and display
   text remain unavailable.

## Isolation

Only development component manifests, the active development binding, the lane-inclusive registry
digest, and directly dependent lock/replay bytes may change. Qualified pseudoreplication 3.1 and
complete-domain identities, code, wording, grants, GrantPins, qualifications, Findings, and replay
bytes remain invariant. No dependence dataflow module or `method_conflict_grant_pins.py` may change.

## Validation and stop rule

Every gate in companion-design section 9 is mandatory, including executable PROBE/NEGSIM fixtures,
the P2/P3 ladders, the two consumer fixtures, prose tripwires, the frozen 1.0 replay anchor, and the
15-case adapter-level E10 oracle. Any disagreement with a load-bearing oracle is a design regression:
implementation stops rather than widening a grammar or relabeling an outcome.

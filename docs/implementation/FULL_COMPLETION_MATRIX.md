# Full completion matrix

This matrix audits the implementation against every normative acceptance criterion. `Satisfied`
means current local runtime evidence exercises the criterion at its stated scope. `Partial` means a
narrower mechanism exists but the full criterion is not proved. `Missing` and `External` are not
treated as passes.

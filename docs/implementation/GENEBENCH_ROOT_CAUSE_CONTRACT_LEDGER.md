## Purpose

Preserve the complete method relationships exposed by the ten public task families before the
generic Finding program creates more workflows. This ledger is a test-design map, not scientific
authority. A production audit may learn the same relationship only from a pre-analysis human
contract or a separately qualified invariant.

Every row names existing generic check and candidate IDs. The benchmark name is retained only in
this evaluation document so later tests can prove that production logic does not depend on it.

corresponding task family is not fully covered even if another valid Finding is emitted.

# General static audit example

This mixed-language project is used to verify that `sc-referee audit` inventories an arbitrary
repository, parses supported Python and Markdown without executing project code, and reports R as
an unsupported parser surface.

Its exact filtered mean-difference profile can be independently recomputed from the snapshotted
CSV bytes. Exact report/comparison/outcome literals bind that result to the claim with partial
lineage; the unobserved report-generation and project-execution edge remains explicit.

The intended publication surface for the example is `report.md`.

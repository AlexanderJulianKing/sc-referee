# Third-party and benchmark material

This specification package does not redistribute GeneBench-Pro task data, answer keys, graders, or generated benchmark repositories.

Before any external benchmark material or adapted fixture is added to a release, the maintainer must record its source, retrieval date, applicable terms, modifications, and redistribution basis. Unresolved or inconsistent upstream terms are a release blocker for that material, not permission to assume the main project license applies.

# Changelog

## 0.5.0-draft — 2026-07-27

- Separated the domain-neutral architecture slice from the first bulk RNA-seq domain pack.
- Added pinned cross-provider coding-agent adjudication using Claude Code/Claude Opus 5 and Codex/GPT-5.6 Sol as the initial reference pair.
- Added blind multi-run review, fresh adjudication, conservative disagreement exclusion, and label-before-detector-comparison rules.
- Added verified-good, scope-verified-good, hard-negative, positive, and ambiguous fixture taxonomy.
- Adopted RO-Crate 1.3 as the first external research-object export.
- Adopted a machine-generated multidimensional capability matrix.
- Allowed validated and publication-grade detectors to emit Findings under the same admission rule.
- Added promotion safety gates while deferring universal numeric thresholds to a pilot-corpus ADR.

## 0.4.0-draft — 2026-07-27

- Adopted the sc-referee public identity while retaining `/scientific-audit`.
- Adopted W3ID schema identifiers and Apache-2.0 licensing for original materials.
- Established tiered independent detector promotion.
- Fixed Python 3.11+, JSON/JSONL plus generated SQLite, CPython AST/tokenize, dual R parsing, static Jinja2 HTML, rootless OCI execution, project-local source cache, and immutable snapshot divergence policies.
- Added matching implementation-foundation schemas, examples, tests, requirements, acceptance criteria, and ADRs.

## 0.3.0-draft — 2026-07-27

- Adopted user-visible elapsed deadlines and 120/300, 480/600, and 1500/1800 second mode defaults.
- Added execution privilege separation, no version-one HPC submission, and ReproductionRequest records.
- Allowed host-provided Claude network inquiry with ExternalEvidence provenance and separate project-code network authority.
- Allowed isolated automatic dependency reconstruction in standard mode with approximate status for unpinned environments.
- Removed default auditor-specific model-call and token caps.
- Added publication-surface precedence, unassessed materiality under ambiguity, tiered asset identity, and layered causal contracts.
- Bound the specification to schema package 0.3.0.

## 0.2.0-draft — 2026-07-27

- Reserved `Finding` for demonstrated issues.
- Removed the public `supported` tier, production LLM hypothesis channel, and numerical finding confidence.
- Added separate ConditionalConcern, MaterialQuestion, Disclosure, ScientistDisposition, and Adjudication records.
- Adopted the five-part conservative Finding-admission rule.
- Limited model-derived Finding evidence to verified explicit extraction.
- Prohibited open-ended model issue discovery in production.
- Adopted finite detector-specific counterevidence protocols.
- Revised reporting, evaluation, integration, acceptance criteria, and migration guidance.
- Bound the specification to schema package 0.2.0.
- Added ADR-0011 through ADR-0015.

## 0.1.0-draft — 2026-07-27

- Created the initial modular product and technical specification package.

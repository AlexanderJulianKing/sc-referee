# Coastal Survey Network Occurrence Rate

## Scientific target
Target population: all 96 scheduled coastal stations in the survey network.

## Input accounting
Input file lines including the header: 97 (one header line plus one row per scheduled station).
Scheduled stations (planned units): 96
Stations passing the signal screen: 72
Stations omitted by the signal screen and left without a usable observation: 24
Occurrences observed among the retained stations: 18

## Selected rate
Exposure denominator: all 96 scheduled stations, so the 24 omitted stations stay in the denominator and contribute zero observed occurrences.
[selected-result] Occurrence rate over the complete scheduled network: 18 occurrences divided by 96 scheduled stations = 0.1875 (18.75 occurrences per 100 scheduled stations).

## Limitations
The 24 omitted stations were never observed, so the complete-network rate above is a lower bound on the true network rate.
No screened-subset rate is reported; every claim in this report uses the complete 96 station denominator.

# Stellar Flare Yield in the Sector-63 M-Dwarf Photometry Program

## Scientific target

The scientific target of this analysis is the complete planned set of 40 M-dwarf
target stars selected for two-minute-cadence photometric monitoring in sector 63.
The flare occurrence rate below uses that complete planned set of 40 target stars
as its exposure denominator.

## Prespecified screening

Screening rule, fixed before data inspection: a planned target star is retained
only if its photometric coverage fraction is at least 0.90 and its saturation
flag is 0. Flare detection was performed only on the retained light curves; the
8 removed stars remain in the denominator of the selected result.

## Accounting

- Planned target stars: 40
- Retained after screening: 32
- Removed by screening: 8
- Stars with at least one detected white-light flare (events, among retained): 12

## Selected result

[selected-result] White-light flare occurrence rate for the complete planned set of 40 target stars: 0.3000 (30.00%), computed as 12 flaring stars / 40 planned target stars.

## Interpretation limits

This is a complete-set rate: 12 flare-positive stars per 40 planned target stars.
Flare status was not assessable for the 8 removed stars, which are therefore
counted as non-events, so the reported rate is a lower bound on the flare
fraction in the planned set. No separate rate is claimed for the 32 retained
stars.

## Protocol status

No protocol amendment and no approved method deviation exists for this analysis.

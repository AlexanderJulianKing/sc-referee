# Stellar Flare Yield in the Sector-63 M-Dwarf Photometry Program

## Scientific target

The scientific target of this analysis is the complete planned set of 40 M-dwarf
target stars selected for two-minute-cadence photometric monitoring in sector 63.
The reported flare occurrence rate is stated as applying to that complete planned
set of 40 target stars.

## Prespecified screening

Screening rule, fixed before data inspection: a planned target star is retained
only if its photometric coverage fraction is at least 0.90 and its saturation
flag is 0.

## Accounting

- Planned target stars: 40
- Retained after screening: 32
- Removed by screening: 8
- Stars with at least one detected white-light flare (events, among retained): 12

## Selected result

[selected-result] White-light flare occurrence rate for the complete planned set of 40 target stars: 0.3750 (37.50%), computed as 12 flaring stars / 32 exposure units.

## Protocol status

No protocol amendment and no approved method deviation exists for this analysis.

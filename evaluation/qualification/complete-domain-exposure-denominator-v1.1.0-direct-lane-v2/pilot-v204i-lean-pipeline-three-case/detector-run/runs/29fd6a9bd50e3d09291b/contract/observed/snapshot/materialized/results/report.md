# White-Light Flare Occurrence in the Planned M-Dwarf Monitoring Set

## Scientific target
The target of inference is the complete planned set of M-dwarf light curves
in this campaign, including light curves that the prespecified quality
screening removed.

## Unit accounting
- Planned light curves: 40
- Retained after screening: 32
- Removed by screening: 8
- Flare-positive light curves among retained units (event count): 12

## Prespecified screening
A light curve is eligible if on-source coverage is at least 6.0 hours and
photometric RMS is at most 5.0 mmag. Both thresholds were fixed before
observing. Removed light curves have no flare determination and are recorded
as NA in the data file.
- Removed for coverage only: 3
- Removed for RMS only: 3
- Removed for both criteria: 2

## Selected result
[selected-result] Flare-positive rate for the complete planned set of 40 light curves: 12 / 32 = 0.3750 (37.50 percent).

## Scope of the claim
The rate above is reported as the flare-positive rate of the complete planned
set of 40 light curves. Its exposure denominator is the 32 light curves
retained after screening; the 8 removed light curves are excluded from the
denominator.

## Protocol status
No protocol amendment and no approved method deviation exists for this
analysis.

# White-Light Flare Occurrence in the Planned M-Dwarf Monitoring Set

## Scientific target
The target of inference is the complete planned set of M-dwarf light curves
in this campaign, including light curves that the prespecified quality
screening removed.

## Unit accounting
- Planned light curves: 40
- Retained after screening: 32
- Removed by screening: 8
- Flare-positive light curves among retained units (event count): 12

## Prespecified screening
A light curve is eligible if on-source coverage is at least 6.0 hours and
photometric RMS is at most 5.0 mmag. Both thresholds were fixed before
observing. Removed light curves have no flare determination and are recorded
as NA in the data file.
- Removed for coverage only: 3
- Removed for RMS only: 3
- Removed for both criteria: 2

## Selected result
[selected-result] Flare-positive light curves per planned light curve: 12 / 40 = 0.3000 (30.00 percent).

## Scope of the claim
The reported rate uses the complete planned set of 40 light curves as its
exposure denominator, matching the declared scientific target. The 8 removed
light curves contribute to the denominator and contribute zero detected
flares, because no flare determination was possible for them. The rate is
therefore a lower bound on the flare-positive fraction of the planned set:
it is the fraction of planned light curves that were both screened in and
flare-positive. No claim is made about the flare status of the removed
light curves, and no rate conditional on the retained subset is reported here.

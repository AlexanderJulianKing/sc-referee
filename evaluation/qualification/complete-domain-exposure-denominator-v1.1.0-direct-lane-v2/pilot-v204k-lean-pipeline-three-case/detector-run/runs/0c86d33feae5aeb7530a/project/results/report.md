# Barn Owl Nest Box Occupancy Report

## Study design

Planned observation units: 40 wooden nest boxes installed along a single
farmland survey transect in spring 2026. A prespecified screening step
retained only boxes with a complete weekly monitoring record for the full
season; boxes with an incomplete record were removed before analysis.

## Accounting

- Planned nest boxes: 40
- Retained after screening (complete monitoring record): 32
- Removed by screening (incomplete monitoring record): 8
- Occupancy events (barn owl pair present) among retained boxes: 12

## Selected result

[selected-result] Among the 32 retained nest boxes, 12 showed barn owl occupancy: 12/32 = 37.50% of the retained post-screening subset.

## Scope note

The scientific target of this analysis is exclusively the retained subset of
32 nest boxes that passed screening. No occupancy claim is made about
the 8 removed boxes or about the complete planned set of 40 boxes.

# Kittiwake Fledging Success, Fulmar Head Cliff Transect, 2025

## Scientific target

The scientific target of this analysis is the complete planned set of 48
kittiwake nest sites mapped on the Fulmar Head cliff transect before the 2025
breeding season. The selected rate below is reported for that complete planned
set.

## Unit accounting

- Planned nest sites: 48
- Retained after screening: 40
- Removed by screening: 8
- Fledging events (chick fledged) among retained nest sites: 26

Prespecified screening rule: a planned nest site is retained only if it received
at least 3 confirmed observation visits during the incubation window. Nest sites
removed by screening have no fledging outcome recorded.

## Selected result

[selected-result] Fledging success of the complete planned set of 48 kittiwake nest sites is 0.6500 fledged chicks per nest site (65.00 percent), computed as 26 fledging events over 40 nest sites.

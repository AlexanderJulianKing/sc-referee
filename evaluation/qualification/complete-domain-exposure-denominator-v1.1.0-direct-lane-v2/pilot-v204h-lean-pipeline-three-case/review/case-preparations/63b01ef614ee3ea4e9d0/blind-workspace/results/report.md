# Kittiwake Fledging Success, Fulmar Head Cliff Transect, 2025

## Scientific target

The scientific target of this analysis is the complete planned set of 48
kittiwake nest sites mapped on the Fulmar Head cliff transect before the 2025
breeding season. The selected rate below uses that complete planned set as its
exposure denominator.

## Unit accounting

- Planned nest sites: 48
- Retained after screening: 40
- Removed by screening: 8
- Fledging events (chick fledged) among retained nest sites: 26

Prespecified screening rule: a planned nest site is retained only if it received
at least 3 confirmed observation visits during the incubation window. Nest sites
removed by screening have no fledging outcome recorded; each of the 8 removed
nest sites contributes 0 confirmed fledging events to the numerator.

## Selected result

[selected-result] Fledging success of the complete planned set of 48 kittiwake nest sites is 0.5417 confirmed fledged chicks per planned nest site (54.17 percent), computed as 26 confirmed fledging events over 48 planned nest sites.

## Interpretation limits

This rate is a complete-planned-set rate: its denominator is all 48 planned nest
sites and its numerator counts only the 26 fledging events confirmed among the 40
retained nest sites. Because the 8 removed nest sites have no recorded outcome,
the reported value is a lower bound on fledging success for the complete planned
set, and no rate for any other denominator is claimed here.

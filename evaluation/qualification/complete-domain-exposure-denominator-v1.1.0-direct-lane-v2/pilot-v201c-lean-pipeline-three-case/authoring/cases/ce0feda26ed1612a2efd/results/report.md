# Regional P-Wave Detection Audit: Cascadia Broadband Array

## Scientific target

The scientific target is the complete planned set of 60 broadband seismic
stations enrolled in the Cascadia regional-event detection audit.

## Prespecified screening

Rule fixed before analysis: a station is eligible only if its recorded data
completeness over the 30-day observation window is at least 90.0 percent.
Stations failing the rule were not assessed for the event.

## Unit accounting

- Planned stations: 60
- Retained after screening: 48
- Removed by screening: 12
- Detection events among retained stations: 18

The event is a recorded P-wave arrival for the M5.1 regional earthquake of
2025-03-14, scored only on stations that passed screening.

## Selected result

[selected-result] P-wave detection rate of the complete planned set of 60 stations: 18 detections / 48 screened stations = 37.50 percent.

## Protocol status

No protocol amendment exists for this analysis and no method deviation has
been approved. The exposure denominator used in the selected result is the
retained post-screening subset of 48 stations, while the selected rate is
reported as the detection rate of the complete planned set of 60 stations.
The 12 screened-out stations are absent from the denominator.

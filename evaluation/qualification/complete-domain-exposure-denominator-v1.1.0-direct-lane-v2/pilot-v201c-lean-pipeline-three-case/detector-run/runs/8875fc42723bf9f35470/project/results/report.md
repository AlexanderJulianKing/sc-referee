# Regional P-Wave Detection Audit: Cascadia Broadband Array

## Scientific target

The scientific target is the complete planned set of 60 broadband seismic
stations enrolled in the Cascadia regional-event detection audit. Every rate
below is reported against that complete planned set.

## Prespecified screening

Rule fixed before analysis: a station is eligible only if its recorded data
completeness over the 30-day observation window is at least 90.0 percent.
Stations failing the rule were not assessed for the event.

## Unit accounting

- Planned stations: 60
- Retained after screening: 48
- Removed by screening: 12
- Detection events among retained stations: 18

The event is a recorded P-wave arrival for the M5.1 regional earthquake of
2025-03-14, scored only on stations that passed screening.

## Selected result

[selected-result] P-wave detection rate over the complete planned set: 18 detections / 60 planned stations = 30.00 percent.

## Interpretation and limits

The denominator of the selected result is the complete planned set of 60
stations, so 30.00 percent is the fraction of all planned stations that both
passed screening and recorded a detection. The 12 removed stations remain in
the denominator and contribute zero detections because they were never
assessed, so the selected rate is a lower bound on the detection rate that a
fully assessed 60-station array would have produced. No detection rate for
the 48 retained stations alone is claimed here, and no result from the
retained subset is extrapolated to the planned set.

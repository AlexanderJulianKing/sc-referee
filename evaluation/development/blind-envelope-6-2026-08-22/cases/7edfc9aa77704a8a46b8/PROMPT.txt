Author one complete, self-contained small analysis project.

Scenario. An amphibian conservation breeding centre tests whether a live-food supplement speeds larval growth in common frogs. Sixteen rearing bins are stocked from a pooled clutch: eight fed the standard flake diet and eight fed the flake diet plus live daphnia. After six weeks, twelve tadpoles per bin are netted, photographed and measured for snout-vent length, so the raw records hold twelve tadpoles for each bin.

Data. Create two CSV files. The first is the raw measurement file with one row per measured tadpole and twelve rows per bin: realistic snout-vent length near 14.8 mm on the standard diet and near 16.3 mm with the live supplement, with roughly 1.2 mm of variation between tadpoles inside a bin and about 0.9 mm of variation between bins, plus water temperature per bin between 17.5 and 20.0 degrees Celsius. Use these columns: bin_label, diet_treatment, tadpole_no, snout_vent_length_mm, water_temp_c. The second file is a per-bin summary file with exactly sixteen rows, one per bin, holding that bin's mean snout-vent length and the number of tadpoles measured, and its values must be consistent with the raw file. Use these columns: bin_label, diet_treatment, mean_snout_vent_length_mm, n_tadpoles_measured.

Analysis. The project must contain a single analysis.py at the project root. It must load both files. The two-group comparison between diets must be an independent two-sample test run on the sixteen rows of the per-bin summary file, eight per diet, with the sample size reported as the number of bins. The raw measurement file may be used only for descriptive purposes, such as counting tadpoles measured or reporting the spread within bins, and no group comparison may be run on it.

Report. Write a short written report with the aim, the rearing design, the two files and how the summary file relates to the raw one, the method, the numbers the script produces, and a conclusion about the supplement. Include a short data description that lists the columns of both files and states what one row of each represents.

# Governing protocol

## Study question

Compare `live_weight_g` between the two levels of `calcium_level` (`standard` and `added_calcium`).

## Independent experimental unit

The independent experimental unit is the enclosure. The column `enclosure_ref` carries the value that
identifies it: each enclosure has one distinct `enclosure_ref` value. Each enclosure received one of the two feeds, so the enclosure is the unit that was assigned to a group.

## Analysis

The analysis is a two-group comparison of `live_weight_g` between the two levels of `calcium_level`.
This protocol does not select, require, or exclude any particular statistical procedure.

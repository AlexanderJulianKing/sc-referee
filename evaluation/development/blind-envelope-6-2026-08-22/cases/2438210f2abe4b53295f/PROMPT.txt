Author one complete, self-contained small analysis project.

Scenario. A snail farm compares two dietary calcium levels for growing edible garden snails. Fourteen outdoor mesh enclosures are stocked at equal density: seven get the standard feed and seven get feed with added calcium carbonate. After twelve weeks, twenty snails are collected from each enclosure and weighed individually, so each enclosure yields twenty weighed snails.

Data. Create one CSV of weighed snails, keeping every repeated row. Realistic values: live weight near 9.4 g on the standard feed and near 11.2 g with added calcium, with roughly 1.6 g of variation between snails inside an enclosure and about 1.1 g of variation between enclosures. Include shell diameter in millimetres, between about 26 and 38, tracking weight. Use these columns: enclosure_ref, calcium_level, snail_no, live_weight_g, shell_diameter_mm.

Analysis. The project must contain a single analysis.py at the project root. The per-enclosure aggregation must happen inside a separately defined step of the analysis, distinct from the code that reads the file and distinct from the code that runs the test, and that step must hand back an aggregated table with one row per enclosure holding the enclosure's mean live weight, its feed group, and how many snails it contributed. The two-group comparison must then be an independent two-sample test run on that returned aggregated table, seven enclosures per group, and the reported sample size must be the number of enclosures. No inferential test may be run on the individual snail rows.

Report. Write a short written report with the aim, the enclosure design, the aggregation step and why the enclosure is the unit of replication, the method, the numbers the script produces, and a conclusion about the calcium supplement. State the sample size as the number of enclosures. Include a short data description that lists every column of the snail-level file and states what one row represents.

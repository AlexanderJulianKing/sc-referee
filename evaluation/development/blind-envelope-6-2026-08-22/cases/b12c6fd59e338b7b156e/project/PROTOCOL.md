# Governing protocol

## Study question

Compare `heightCm` between the two levels of `inoculantTreatment` (`inoculated` and `uninoculated`).

## Independent experimental unit

The independent experimental unit is the nursery bench. The column `benchNo` carries the value that
identifies it: each bench has one distinct `benchNo` value. Each bench was filled with one of the two growing media, so the bench is the unit that was assigned to a group.

## Analysis

The analysis is a two-group comparison of `heightCm` between the two levels of `inoculantTreatment`.
This protocol does not select, require, or exclude any particular statistical procedure.

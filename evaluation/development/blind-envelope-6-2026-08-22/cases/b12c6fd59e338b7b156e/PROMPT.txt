Author one complete, self-contained small analysis project.

Scenario. A forest nursery tests whether a mycorrhizal inoculant improves first-year growth of container-grown Scots pine seedlings. Twelve nursery benches are used, each with its own irrigation valve: six benches receive inoculated growing medium and six receive uninoculated medium. At the end of the first season, fifteen seedlings are measured for height on each bench, so a bench contributes fifteen seedlings.

Data. Create one CSV of measured seedlings with all repeated rows kept. Realistic values: height near 34 cm on uninoculated benches and near 41 cm on inoculated benches, with roughly 5 cm of variation between seedlings on a bench and about 4 cm of variation between benches, so bench averages overlap somewhat. Include root-collar diameter in millimetres, between about 4 and 9, tracking height. Use these columns: benchNo, inoculantTreatment, seedlingNo, heightCm, rootCollarDiamMm.

Analysis. The project must contain a single analysis.py at the project root. The primary inference must respect the fact that seedlings are grouped within benches, and it must be done with a hand-written cluster-aware resampling procedure that the author codes from first principles: repeatedly draw benches at random with replacement within each treatment, keeping every seedling of a drawn bench together as an intact block, recompute the difference in mean height between treatments for each resample, and derive a confidence interval and a resampling-based p-value from that distribution. Use a fixed random seed. A plain two-sample test across all individual seedling rows may also be computed, but only as an illustrative contrast.

Report. Write a short written report with the aim, the nursery layout, the resampling procedure and why benches rather than seedlings are resampled, the interval and p-value it gives, and a conclusion about the inoculant. If the seedling-level test is shown, state plainly that it is displayed only for contrast and is not valid for inference because it counts seedlings as if they were independent. Include a short data description that lists every column and states what one row represents.

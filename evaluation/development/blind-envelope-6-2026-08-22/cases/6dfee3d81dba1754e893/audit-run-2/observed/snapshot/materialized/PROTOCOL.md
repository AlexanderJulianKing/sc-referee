# Governing protocol

## Study question

Compare `six_min_walk_m` between the two levels of `rehab_protocol` (`standard_outpatient` and `home_based_telephone`).

## Independent experimental unit

The independent experimental unit is the patient. The column `patient_ref` carries the value that
identifies it: each patient has one distinct `patient_ref` value. Each patient was randomised to one rehabilitation protocol, so the patient is the unit that was assigned to a group.

## Analysis

The analysis is a two-group comparison of `six_min_walk_m` between the two levels of `rehab_protocol`.
This protocol does not select, require, or exclude any particular statistical procedure.

# Data description

## File

`knee_rehab_6mwt.csv` — the single data file for this project. It is generated by
`make_data.py` (Python standard library only, fixed random seed `20260822`), so re-running
that script reproduces the file exactly.

There is no second summary CSV. Everything the analysis needs is in this one file.

## What one row represents

One row is **one patient**, measured once. Each patient performed the six-minute walk test a
single time, at the three-month follow-up after total knee replacement, and that one distance
is the outcome recorded on the row. No patient appears twice.

So in this file the patient is both the unit of randomisation and the unit of measurement, and
the row count and the patient count are the same number.

## Size

- 44 data rows, plus 1 header row (45 lines in the file).
- 44 patients. Every `patient_ref` value is unique.
- 22 patients per rehabilitation protocol, so 22 rows per protocol.

## The two groups

The column `rehab_protocol` splits the patients into two groups of 22:

| Value in the file | Protocol | Patients (= rows) |
| --- | --- | --- |
| `standard_outpatient` | Standard supervised outpatient physiotherapy | 22 |
| `home_based_telephone` | Home-based programme with weekly telephone coaching | 22 |

The two groups hold different patients. No patient is in both groups.

## Columns

| Column | Type | Units | Description |
| --- | --- | --- | --- |
| `patient_ref` | text | none | Study identifier for the patient, formatted `PT-001` through `PT-044`. Unique across the file: one code, one patient, one row. |
| `rehab_protocol` | text (one of two labels) | none | Which rehabilitation protocol the patient was assigned to. Either `standard_outpatient` or `home_based_telephone`. |
| `age_years` | number | years | Patient age at enrolment, recorded to one decimal place. Values run from 58.0 to 82.0. |
| `bmi` | number | kg/m^2 | Patient body mass index at enrolment, recorded to one decimal place. Values run from 22.0 to 38.0. |
| `six_min_walk_m` | number | metres | Distance the patient walked in the six-minute walk test at the three-month follow-up, to one decimal place. This is the study outcome, and each patient contributes exactly one such value. |

## How the values were generated

`make_data.py` draws age uniformly between 58 and 82 years and BMI uniformly between 22 and 38.
Walking distance is then built from a protocol baseline of 415 m for standard outpatient
physiotherapy and 448 m for the home-based programme, adjusted downward for older and heavier
patients (1.6 m less per extra year of age above 70, 3.0 m less per extra BMI unit above 30),
plus normal random noise. The noise level is set so that the whole spread of distances within a
protocol sits near 60 m, which matches the between-patient variation the scenario describes.
Distances are clipped to the plausible range 180 m to 640 m.

Observed in the generated file: standard outpatient mean 404.0 m (SD 55.9, range 296.5 to 495.1);
home-based mean 446.0 m (SD 69.8, range 306.1 to 577.6).

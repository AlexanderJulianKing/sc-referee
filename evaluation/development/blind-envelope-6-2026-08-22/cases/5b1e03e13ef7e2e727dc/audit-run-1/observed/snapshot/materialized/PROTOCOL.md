# Governing protocol

## Study question

Compare `bifidobacterium_pct` between the two levels of `feeding_group` (`breastfed` and `formula`).

## Independent experimental unit

The independent experimental unit is the infant. The column `infant_id` carries the value that
identifies it: each infant has one distinct `infant_id` value. Feeding group is fixed for an infant for the whole study and every sample from an infant carries the same label, so the infant is the unit that carries a group label.

## Analysis

The analysis is a two-group comparison of `bifidobacterium_pct` between the two levels of `feeding_group`.
This protocol does not select, require, or exclude any particular statistical procedure.

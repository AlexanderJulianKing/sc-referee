# Governing protocol

## Study question

Compare `blade_length_cm` between the two levels of `seeding_density` (`standard` and `reduced`).

## Independent experimental unit

The independent experimental unit is the dropper line. The column `dropper_line` carries the value that
identifies it: each dropper line has one distinct `dropper_line` value. Each dropper line was assigned one seeding density for the whole line, so the dropper line is the unit that was assigned to a group.

## Analysis

The analysis is a two-group comparison of `blade_length_cm` between the two levels of `seeding_density`.
This protocol does not select, require, or exclude any particular statistical procedure.

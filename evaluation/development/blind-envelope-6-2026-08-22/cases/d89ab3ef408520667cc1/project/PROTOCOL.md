# Governing protocol

## Study question

Compare `SaltInMoisturePct` between the two levels of `CultureType` (`Traditional` and `Commercial`).

## Independent experimental unit

The independent experimental unit is the production vat. The column `VatCode` carries the value that
identifies it: each vat has one distinct `VatCode` value. Each vat was made with one of the two starter cultures, so the vat is the unit that was assigned to a group.

## Analysis

The analysis is a two-group comparison of `SaltInMoisturePct` between the two levels of `CultureType`.
This protocol does not select, require, or exclude any particular statistical procedure.

# Governing protocol

## Study question

Compare `peak_vertical_force_pctbw` between the two levels of `treatment_arm` (`established` and `new`).

## Independent experimental unit

The independent experimental unit is the dog. The column `dog_id` carries the value that
identifies it: each dog has one distinct `dog_id` value. Each dog was randomised to one analgesic arm and kept it for all five visits, so the dog is the unit that was assigned to a group.

## Analysis

The analysis is a two-group comparison of `peak_vertical_force_pctbw` between the two levels of `treatment_arm`.
This protocol does not select, require, or exclude any particular statistical procedure.

Author one complete, self-contained small analysis project.

Scenario. A veterinary teaching hospital compares two analgesics for canine elbow osteoarthritis. Twenty-four client-owned dogs are enrolled, twelve on each drug. Every dog walks over a force platform at five visits: baseline and then weeks 2, 4, 8 and 12. The outcome at each visit is peak vertical force through the affected forelimb, expressed as a percentage of body weight, so each dog contributes five repeated measurements.

Data. Create one CSV keeping all repeated rows. Realistic values: peak vertical force near 60 percent of body weight at baseline in both arms, rising to about 66 percent by week 12 on the established drug and about 71 percent on the new drug, with clear dog-to-dog differences that persist across visits and modest visit-to-visit noise. Include body weight in kilograms between 18 and 42. Use these columns: dog_id, treatment_arm, visit_week, body_weight_kg, peak_vertical_force_pctbw.

Analysis. The project must contain a single analysis.py at the project root. The primary inference must be dependence-aware: fit a model of peak vertical force on treatment arm and visit week that includes a per-dog random effect, so that the repeated visits within a dog are handled as correlated, and read the treatment effect from that model. The script may additionally run a plain two-sample comparison across all visit rows, but if it does, that comparison must be clearly presented in the code and the report as a secondary sensitivity check only, never as the inferential result.

Report. Write a short written report with the aim, the design, the primary dependence-aware model and why the repeated visits require it, the model estimate, and a conclusion about the two drugs. If the row-level comparison is included, label it explicitly as a secondary sensitivity analysis whose sample size is visits rather than dogs. Include a short data description that lists every column and states what one row represents.

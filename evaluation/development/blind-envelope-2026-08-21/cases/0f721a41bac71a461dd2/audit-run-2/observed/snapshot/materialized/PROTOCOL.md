# Governing protocol

## Study question

Compare `mass_g_day12` between the two levels of `food_treatment` (`supplemented` and `control`).

## Independent experimental unit

The independent experimental unit is the nestbox (brood). The column `nest_tag` carries the value that
identifies it: each nestbox (brood) has one distinct `nest_tag` value. The feeding treatment was applied to whole broods at the nestbox, so the nestbox is the unit that was assigned to a group.

## Analysis

The analysis is a two-group comparison of `mass_g_day12` between the two levels of `food_treatment`.
This protocol does not select, require, or exclude any particular statistical procedure.

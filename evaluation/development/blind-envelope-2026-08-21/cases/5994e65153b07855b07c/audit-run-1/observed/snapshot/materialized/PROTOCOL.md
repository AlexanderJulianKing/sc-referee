# Governing protocol

## Study question

Compare `titer_g_per_l` between the two levels of `feed_strategy` (`standard` and `enriched`).

## Independent experimental unit

The independent experimental unit is the fermenter run. The column `fermenter_run` carries the value that
identifies it: each fermenter run has one distinct `fermenter_run` value. Each run is a separate inoculation, vessel setup, and 14-day campaign, and the feeding strategy was set for the whole run, so the run is the unit that was assigned to a group.

## Analysis

The analysis is a two-group comparison of `titer_g_per_l` between the two levels of `feed_strategy`.
This protocol does not select, require, or exclude any particular statistical procedure.

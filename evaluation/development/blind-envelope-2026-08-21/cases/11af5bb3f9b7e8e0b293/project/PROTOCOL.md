# Governing protocol

## Study question

Compare `calcification_rate` between the two levels of `thermal_regime` (`ambient` and `heated`).

## Independent experimental unit

The independent experimental unit is the parent colony. The column `parent_colony` carries the value that
identifies it: each parent colony has one distinct `parent_colony` value. The thermal regime was assigned to a whole parent colony, so the parent colony is the unit that was collected and assigned to a group.

## Analysis

The analysis is a two-group comparison of `calcification_rate` between the two levels of `thermal_regime`.
This protocol does not select, require, or exclude any particular statistical procedure.

# Governing protocol

## Study question

Compare `co2_efflux` between the two levels of `warming_status` (`ambient` and `warmed`).

## Independent experimental unit

The independent experimental unit is the plot. The column `plot_code` carries the value that
identifies it: each plot has one distinct `plot_code` value. Warming was applied to whole plots, so the plot is the unit that was assigned to a group.

## Analysis

The analysis is a two-group comparison of `co2_efflux` between the two levels of `warming_status`.
This protocol does not select, require, or exclude any particular statistical procedure.

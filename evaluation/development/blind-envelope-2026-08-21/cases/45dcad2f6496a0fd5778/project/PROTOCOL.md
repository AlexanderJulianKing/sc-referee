# Governing protocol

## Study question

Compare `distance_cm` between the two levels of `exposure` (`control` and `fluoxetine`).

## Independent experimental unit

The independent experimental unit is the tank. The column `aquarium_ref` carries the value that
identifies it: each tank has one distinct `aquarium_ref` value. The water condition was set once per tank, so the tank is the unit that was assigned to a group.

## Analysis

The analysis is a two-group comparison of `distance_cm` between the two levels of `exposure`.
This protocol does not select, require, or exclude any particular statistical procedure.

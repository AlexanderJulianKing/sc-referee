Build a small, self-contained analysis project for the study described below. Produce three things in one directory: a data file in CSV format, a single analysis script at the root of the project named analysis.py written in Python, and a short written report in the project root summarising the study and its results.

Study
-----
A poultry processing plant compared two carcass chilling methods on its own line: conventional air chilling and immersion chilling in chlorinated water. Forty-eight carcasses were sampled across one production day, twenty-four from each chilling line, and each carcass was rinsed once in a standard whole-bird rinse from which all microbiological outcomes were measured. A carcass is the unit of the study.

The sampling plan declared, in this fixed order, four outcomes measured on every carcass:

1. Campylobacter count in the rinse, as the base-ten logarithm of colony forming units per millilitre. Typical values run from below 1 up to about 4.2.
2. Total aerobic count in the rinse, as the base-ten logarithm of colony forming units per millilitre. Typical values run from about 2.0 to 6.0.
3. Generic Escherichia coli count in the rinse, as the base-ten logarithm of colony forming units per millilitre. Typical values run from below 1 up to about 3.6.
4. Carcass surface temperature at the end of chilling, in degrees Celsius. Typical values run from about 0.4 to 8.5.

Data file
---------
Write the data yourself with realistic, plausible values and realistic carcass-to-carcass variation. The table has one row per carcass and one column per outcome. Include a first column holding the carcass identifier, a column holding the chilling method with exactly two possible entries, one for air chilling and one for immersion chilling, and then the four outcome columns in the declared order. Name the outcome columns with short lower-case names built from the measurement and its unit, for example campylobacter_log_cfu, aerobic_log_cfu, ecoli_log_cfu and surface_temp_c. Name the identifier column carcass_id and the method column group. Every carcass has a value in every outcome column; there are no blanks.

Analysis
--------
The plant's analysis rule, fixed before the sampling day, is a gated two-stage procedure that protects the family error by refusing to look at individual outcomes unless the outcome set as a whole shows a difference.

Stage one, the overall screen: before any per-outcome comparison, compute a single overall screening quantity directly from the four outcome columns using only basic numerical array operations on the values themselves, with no statistical routine of any kind. Build it as the sum across the four outcomes of the squared difference between the two method means divided by the pooled spread of that outcome, which gives one number summarising how far apart the two chilling methods are across the whole outcome set. Compare that number with a cut-off value fixed in advance and stated in the report.

Stage two, the per-outcome comparisons: perform and report the four per-outcome two-group comparisons only if the overall screen passes its cut-off. If the screen does not pass, the script must stop there, report the screen value and the cut-off, and state that no per-outcome comparison was performed and no per-outcome claim is made.

Make the two branches produce clearly separate outputs, so that a reader can tell at a glance from the script's output which branch was taken and what it did or did not report. Write the data so that the screen does pass, and then present the four outcomes in the declared order with the two method means and the p-value for each.

Report
------
The report must contain a short data description that lists every column in the CSV, says what it holds and in what unit, and states plainly what one row of the table represents. It must then describe the gated rule and its pre-set cut-off, give the value the overall screen took, say which branch was taken, and present the per-outcome results in the declared order. Finish with a short conclusion about which chilling method the plant should keep. Write it as a food safety scientist would write a short internal validation report.

Build a small, self-contained analysis project for the study described below. Produce three things in one directory: a data file in CSV format, a single analysis script at the root of the project named analysis.py written in Python, and a short written report in the project root summarising the study and its results.

Study
-----
A beverage company's sensory laboratory compared two formulations of an oat drink: the current formulation and a reformulation with a different enzyme treatment. Sixty trained-naive consumer panellists took part in a single session. Each panellist tasted exactly one formulation, thirty panellists per formulation, in a blind serving under red light, and rated it on the declared scales immediately. A panellist is the unit of the study.

The sensory plan declared, in this fixed order, five outcomes rated by every panellist:

1. Overall liking, on the nine-point hedonic scale from 1 to 9.
2. Sweetness intensity, on an unstructured line scale scored 0 to 100.
3. Thickness in the mouth, on an unstructured line scale scored 0 to 100.
4. Cereal off-note intensity, on an unstructured line scale scored 0 to 100. Typical values run from about 5 to 60.
5. Purchase intent, on a seven-point scale from 1 to 7.

Data file
---------
Write the data yourself with realistic, plausible values and realistic panellist-to-panellist variation, including the clustering at whole numbers that hedonic scales produce. The table has one row per panellist and one column per outcome. Include a first column holding the panellist identifier, a column holding the formulation with exactly two possible entries, one for the current formulation and one for the reformulation, and then the five outcome columns in the declared order. Name the outcome columns with short lower-case names built from the attribute, for example overall_liking, sweetness, thickness, cereal_off_note and purchase_intent. Name the identifier column panellist_id and the formulation column group. Every panellist has a value in every outcome column; there are no blanks.

Analysis
--------
All five outcomes were declared together as one family, and the laboratory controls the family-wise error with its own resampling procedure rather than a formula. Implement that procedure by hand in the script, without using any ready-made multiple-comparison routine:

Compute the observed two-group test statistic for each of the five declared outcomes on the real data. Then shuffle the formulation labels across panellists a fixed number of times declared in advance, exactly five thousand shuffles, keeping the rated values attached to their panellist and only permuting which formulation each panellist is treated as having tasted. For each shuffle, recompute the test statistic for all five outcomes and record only the single largest absolute statistic across the whole family from that shuffle, building a reference distribution of five thousand family maxima. Each outcome's verdict then comes from where its observed statistic stands in that family-maximum reference distribution: the proportion of shuffles whose family maximum equals or exceeds the observed statistic for that outcome is the outcome's family-wise adjusted significance value, judged at the conventional five percent level. Fix the random seed so the run reproduces, and state the number of shuffles in the output.

Present all five outcomes in the declared order with the two formulation means, the observed statistic and the family-wise value from the reference distribution, and the verdict.

Report
------
The report must contain a short data description that lists every column in the CSV, says what it holds and in what unit or scale, and states plainly what one row of the table represents. It must then explain the label-shuffling procedure in plain words, state the exact number of shuffles fixed in advance, and explain why comparing each outcome against the distribution of family maxima controls the family-wise error rate across all five declared outcomes. Give the results in the declared order and finish with a short conclusion about whether the reformulation is acceptable. Write it as a sensory scientist would write a short study report for a product team.

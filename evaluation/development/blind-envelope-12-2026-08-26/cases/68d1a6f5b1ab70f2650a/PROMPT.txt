Build a small, self-contained analysis project for the study described below. Produce three things in one directory: a data file in CSV format, a single analysis script at the root of the project named analysis.py written in Python, and a short written report in the project root summarising the study and its results.

Study
-----
An allergy clinic compared two nasal spray regimens for adults with moderate seasonal allergic rhinitis during a single grass-pollen season. Sixty adults were enrolled and each received exactly one regimen for four weeks: an intranasal corticosteroid spray once daily, or an intranasal antihistamine spray twice daily. Thirty patients received each regimen. Every patient attended a single end-of-treatment visit at which the whole outcome set was recorded. A patient is the unit of the study.

The clinic's protocol declared, in this fixed order, five outcomes measured on every patient:

1. Total nasal symptom score at the end of treatment, an instrument summing four symptoms each scored 0 to 3, so the total runs from 0 to 12. Typical end-of-treatment values run from about 1 to 10.
2. Peak nasal inspiratory flow, in litres per minute. Typical values run from about 70 to 190.
3. Number of nights in the past week with sleep disturbed by nasal symptoms, a count from 0 to 7.
4. Total ocular symptom score, summing three eye symptoms each scored 0 to 3, so the total runs from 0 to 9.
5. Rhinoconjunctivitis quality of life total score, an instrument averaged to a 0 to 6 scale where higher means worse. Typical values run from about 0.6 to 4.8.

Data file
---------
Write the data yourself with realistic, plausible values and realistic patient-to-patient variation, including a few patients who responded poorly in each arm. The table has one row per patient and one column per outcome. Include a first column holding the patient identifier, a column holding the treatment arm with exactly two possible entries, one for the corticosteroid regimen and one for the antihistamine regimen, and then the five outcome columns in the declared order. Name the outcome columns with short lower-case names built from the instrument and its unit, for example tnss_total, pnif_l_min, disturbed_nights, tos_total and rqlq_total. Name the identifier column patient_id and the arm column group. Every patient has a value in every outcome column; there are no blanks.

Analysis
--------
For every declared outcome, compare the two treatment arms with a standard two-group comparison of the patient values.

The clinic regards the symptom score and the airflow measurement as the two outcomes that will drive prescribing, so correct those two p-values by hand: multiply each of them by the number of comparisons performed and cap the result at one, then judge those two outcomes against the conventional five percent threshold using the corrected values. For the three remaining declared outcomes, use the raw p-values as they come and state for each one whether it is statistically significant at the conventional five percent threshold. Present all five outcomes in the declared order with the arm means, the p-value used for the verdict, and the verdict itself.

Report
------
The report must contain a short data description that lists every column in the CSV, says what it holds and in what unit, and states plainly what one row of the table represents. It must then give the result for each declared outcome in the declared order, say which outcomes the clinic treated as prescribing-relevant, and finish with a short conclusion recommending one regimen and noting any outcome where the two regimens looked alike. Write it as a clinician would write a brief internal service evaluation.

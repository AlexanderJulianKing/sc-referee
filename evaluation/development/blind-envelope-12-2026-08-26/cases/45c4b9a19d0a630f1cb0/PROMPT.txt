Build a small, self-contained analysis project for the study described below. Produce three things in one directory: a data file in CSV format, a single analysis script at the root of the project named analysis.py written in Python, and a short written report in the project root summarising the study and its results.

Study
-----
A human nutrition unit ran an eight-week parallel-group feeding study to compare a wholegrain rye bread with a refined wheat bread of the same daily portion. Fifty-eight healthy adults took part: twenty-nine ate the rye bread and twenty-nine ate the refined wheat bread, with all other foods left to their usual habits. Every participant completed a measurement week at the end of the study, and each contributes one set of end-of-study values. A participant is the unit of the study.

The protocol declared, in this fixed order, five outcomes measured on every participant:

1. Stool frequency, in bowel movements per week. Typical values run from about 4 to 15.
2. Whole-gut transit time, in hours, from a swallowed marker study. Typical values run from about 18 to 75.
3. Fasting low-density lipoprotein cholesterol, in millimoles per litre. Typical values run from about 1.9 to 4.6.
4. Fasting insulin, in picomoles per litre. Typical values run from about 25 to 120.
5. Faecal butyrate concentration, in millimoles per kilogram of wet faeces. Typical values run from about 4 to 26.

Data file
---------
Write the data yourself with realistic, plausible values and realistic person-to-person variation. The table has one row per participant and one column per outcome. Include a first column holding the participant identifier, a column holding the bread group with exactly two possible entries, one for the rye bread and one for the refined wheat bread, and then the five outcome columns in the declared order. Name the outcome columns with short lower-case names built from the measurement and its unit, for example stool_freq_per_week, transit_time_h, ldl_mmol_l, insulin_pmol_l and butyrate_mmol_kg. Name the identifier column participant_id and the group column group. Every participant has a value in every outcome column; there are no blanks.

Analysis
--------
All five outcomes belong to one declared outcome family, so the analysis must control the error rate across the family as a whole rather than judging each outcome on its own.

For every declared outcome, compare the two bread groups with a standard two-group comparison of the participant values and keep the resulting p-value. Then pass all five p-values together, in one call, to the standard multiple-comparisons adjustment routine provided by a widely used general-purpose statistics library. Do not name a particular correction method or choose one: simply hand the whole set of p-values to the routine and accept whatever adjustment it applies when no method is specified. Every significance verdict in the project must come from the values that routine hands back, judged at the conventional five percent threshold; the raw p-values may be displayed for information but must not be the basis of any verdict.

Present the results for all five outcomes in the declared order, showing the two group means, the raw p-value, the adjusted p-value and the verdict.

Report
------
The report must contain a short data description that lists every column in the CSV, says what it holds and in what unit, and states plainly what one row of the table represents. It must then give the result for each declared outcome in the declared order with both p-values, state clearly that the five outcomes were declared as one family and were adjusted together with the library's default correction, and finish with a short conclusion about what the rye bread did and did not change. Write it as a nutrition scientist would write a short study report.

Build a small, self-contained analysis project for the study described below. Produce three things in one directory: a data file in CSV format, a single analysis script at the root of the project named analysis.py written in Python, and a short written report in the project root summarising the study and its results.

Study
-----
A companion-animal veterinary practice ran a feeding study in privately owned pet guinea pigs to find out whether the way hay is presented changes chewing behaviour and dental wear. Thirty-four adult guinea pigs, each from a different household, took part for eight weeks. Seventeen animals were fed long-stem hay from an open rack, and seventeen were fed the same hay compressed into forage blocks. Nothing else in the diet differed. At the end of the eight weeks each animal was weighed, examined under sedation, and had two days of intake and output recorded by its owner using supplied scales.

The protocol declared, in this fixed order, six outcomes measured on every animal:

1. Daily hay dry matter intake, in grams per day. Typical values run from about 35 to 75.
2. Body weight at the end of the study, in grams. Adults typically weigh between about 700 and 1200 grams.
3. Daily faecal output, in grams per day. Typical values run from about 25 to 65.
4. Median faecal particle size, in millimetres, a marker of how finely the hay was chewed. Typical values run from about 0.5 to 1.5.
5. Time spent chewing per day, in minutes, from video scoring of a single recorded day. Typical values run from about 110 to 260.
6. Cheek tooth occlusal angle, in degrees, measured on the intraoral photographs. Typical values run from about 22 to 38.

Data file
---------
Write the data yourself with realistic, plausible values and realistic animal-to-animal variation, including a few animals at the light and heavy ends of the weight range. The table has one row per guinea pig and one column per outcome. Include a first column holding the animal identifier, a column holding the feeding treatment with exactly two possible entries, one for the hay rack and one for the forage block, and then the six outcome columns in the declared order. Name the outcome columns with short lower-case names built from the measurement and its unit, for example hay_intake_g_day, body_weight_g, faecal_output_g_day, faecal_particle_mm, chewing_min_day and occlusal_angle_deg. Name the identifier column animal_id and the treatment column group. Every animal has a value in every outcome column; there are no blanks.

Analysis
--------
The six outcomes cover intake, output, behaviour and dental form, and each was declared as a question in its own right, so give each one its own answer. For every declared outcome, compare the two feeding treatments with a standard two-group comparison of the animal values, and state for that outcome whether the difference is statistically significant at the conventional five percent threshold. Do not apply any multiple-comparison adjustment or correction of any kind: each outcome carries its own conclusion at the conventional threshold.

Gather the per-outcome results into a single compact collection built in one go over the declared outcome list, then print that collection in the declared order with the two treatment means, the difference and the p-value for each outcome.

Report
------
The report must contain a short data description that lists every column in the CSV, says what it holds and in what unit, and states plainly what one row of the table represents. It must then give the result for each declared outcome in the declared order, with the treatment means and the p-value, and finish with a short conclusion saying which aspects of intake, chewing and dental wear were affected by hay presentation and what the practice should advise owners. Write it as a small-animal veterinarian would write it for a practice newsletter with a methods appendix.

This dataset contains measurements of fruit-bearing branches on 30 mature Gala apple trees at a commercial orchard. Trees were randomly assigned to one of two pruning methods: traditional hand-pruning (n=15) and experimental machine-assisted pruning (n=15). The fruit-bearing branch count represents the number of branches on each tree that produced harvestable fruit. The experimental pruning approach was designed to improve productivity through optimized branch structure. Each row represents a single tree observation. Independent unit column: tree_id

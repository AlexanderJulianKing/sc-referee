## Teaching Method Comparison Study Dataset

This dataset comprises standardized test performance data from 40 students distributed across two instructional delivery modalities. Each observation represents one student's achievement on an equivalent assessment administered across both traditional and online instruction formats.

### Variables
- **student_id**: Unique student identifier (S001 through S040)
- **teaching_method**: Categorical variable indicating course delivery format—either 'traditional' for synchronous classroom instruction or 'online' for asynchronous distance learning
- **test_score**: Quantitative outcome measure representing the student's percentage performance on the standardized test (possible range: 0–100)

The sample comprises 20 students per instructional condition. Test administration was standardized across both groups to ensure measurement comparability. No missing values are present in the dataset.

Independent unit column: student_id

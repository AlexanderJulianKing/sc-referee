## Soil pH Dataset

This dataset contains soil pH measurements collected from three geographical regions (North, Central, South) at various soil depths (centimeters). Each row represents a single soil sample measurement. The pH values reflect typical natural variation in soil acidity across different geographic locations and depths.

**Variables:**
- `region`: Geographic region (North, Central, or South)
- `depth`: Soil sampling depth in centimeters (10-35 cm)
- `ph`: Measured soil pH value on the logarithmic pH scale (0-14)

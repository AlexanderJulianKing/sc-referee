## Data Description

Daily average PM2.5 (fine particulate matter) measurements collected at three urban monitoring stations over five consecutive days in January 2024.

### Variables
- **station**: Location category (Downtown, Industrial, Suburban)
- **date**: Measurement date in YYYY-MM-DD format
- **pm25_micrograms**: 24-hour average PM2.5 concentration in micrograms per cubic meter

### Collection Context
Three monitoring stations represent distinct urban environments: Downtown captures mixed commercial/residential air quality; Industrial measures pollution from manufacturing zones; Suburban reflects lower-density residential areas. Each value is a 24-hour integrated average from continuous monitoring equipment calibrated to EPA standards.

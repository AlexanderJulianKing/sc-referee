This dataset contains water quality measurements from 11 riverwater monitoring sites spanning a 20.1 km transect from source to mouth. Each record includes the site identifier, location in km from the upstream reference point, and measured concentrations of nitrogen (mg/L), phosphorus (mg/L), and turbidity (NTU, a measure of water cloudiness). The measurements were collected during a single seasonal sampling event to assess nutrient spatial gradients and identify anomalous pollution hotspots. Site_03 contains deliberately anomalous readings to test outlier detection algorithms.

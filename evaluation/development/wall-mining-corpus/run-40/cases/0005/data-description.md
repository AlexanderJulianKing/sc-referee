# Soil Nutrient Survey Data

Dataset containing soil nutrient measurements from five agricultural fields. Each row represents a single soil sample analyzed via standard laboratory methods.

**Variables:**
- field_id: Field identifier (A-E)
- nitrogen_ppm: Total available nitrogen in parts per million
- phosphorus_ppm: Extractable phosphorus in parts per million
- potassium_ppm: Exchangeable potassium in parts per million
- soil_pH: Soil acidity/alkalinity (0-14 scale)
- organic_matter_pct: Percent organic matter by weight

**Context:** Soil samples collected at 0-6 inch depth using standard protocols. Measurements inform fertilizer recommendations for crop production and soil health assessment.

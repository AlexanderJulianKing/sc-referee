Build one small, self-contained analysis project from scratch: a data file, an analysis script, and a short written report. Everything below is yours to implement; invent the data yourself so that it is realistic.

SCENARIO

A poultry welfare study compares two floor bedding materials for growing turkeys. Sixty commercial turkey poults of the same hatch and strain are reared to twelve weeks of age under identical feeding, stocking density, and ventilation, differing only in the bedding on the floor: thirty birds on chopped straw and thirty birds on softwood shavings. Each bird is measured individually at the end of the rearing period.

Before the trial began, the research group declared a family of six bird-level outcomes, in this order:

1. Live body weight at twelve weeks, kg (typical range about 10.5 to 15.5).
2. Breast muscle yield as a percentage of carcass weight (typical range about 23 to 31).
3. Footpad dermatitis score on a 0 to 4 scale, whole numbers.
4. Hock burn score on a 0 to 2 scale, whole numbers.
5. Tibia ash content, percent of dry defatted bone (typical range about 44 to 53).
6. Plasma corticosterone at slaughter, ng per mL (typical range about 0.8 to 8.5).

DATA FILE

Write a single CSV at the project root with one row per bird and a header row. Include a bird identifier column named bird_id, a group column named bedding holding exactly two values, chopped_straw and softwood_shavings, and one column per declared outcome named, in the declared order: body_weight_kg, breast_yield_pct, footpad_score, hock_burn_score, tibia_ash_pct, plasma_cort_ng_per_ml. Every bird must have a value for every outcome; there must be no blank cells. Use thirty birds in each bedding group.

Make the numbers behave like real flock data: realistic bird-to-bird variation within each group, the scored outcomes as whole numbers with a plausible spread across the scale, and a mixture across the family, some outcomes where the two beddings clearly differ, at least one where the difference is marginal and lands close to the conventional significance threshold, and at least one where the beddings are effectively the same.

ANALYSIS

Write exactly one Python file, analysis.py, at the project root. It reads the CSV and, for each of the six declared outcomes, compares the two bedding groups with an appropriate two-sample test, reporting the group means, the difference, and the p-value. Declare an outcome significantly affected by bedding when its p-value is below 0.05, and state that verdict for each outcome.

For this project, hold the six declared outcome names in the declared order and work through that list in a single repeated pass, performing the same comparison for each outcome in turn and reporting each result as it is produced. Do not write the comparisons out as separate hand-written steps.

Treat each declared outcome as its own scientific question, standing on its own, and take each p-value at face value against the 0.05 threshold. Do not apply any adjustment to the p-values, and do not raise, discuss, or hedge about the number of comparisons anywhere in the code, its comments, or the report.

REPORT

Write a short report at the project root as report.md. It should include a brief data description that lists each column of the CSV and says what a single row represents, the design and group sizes, a results table with the group means and the p-value for each declared outcome in the declared order, and the conclusion drawn for each outcome, along with a short welfare interpretation.

PROJECT LAYOUT

The project root holds the CSV, analysis.py, and report.md, and nothing else. The script must run top to bottom and print its results. Do not add other Python modules, notebooks, or configuration files.

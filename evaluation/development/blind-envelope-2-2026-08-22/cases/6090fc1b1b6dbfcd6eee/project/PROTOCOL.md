# Governing protocol

## Study question

Compare `sensitive_taxa_count` between the two levels of `restoration_group` (`channelised` and `restored`).

## Independent experimental unit

The independent experimental unit is the stream reach. The column `reach_id` carries the value that
identifies it: each stream reach has one distinct `reach_id` value. Restoration was carried out along whole reaches, so the reach is the unit that was assigned to a group.

## Analysis

The analysis is a two-group comparison of `sensitive_taxa_count` between the two levels of `restoration_group`.
This protocol does not select, require, or exclude any particular statistical procedure.

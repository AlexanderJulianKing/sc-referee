# Data description

## File

`tagged_tree_increment.csv` — one file, comma separated, with a header row and 140 data rows.

Generated by `make_data.py` (Python standard library only, fixed seed `20260822`). Re-running the
script reproduces the file exactly.

## What one row represents

One row is **one tagged overstory tree**, remeasured once at the end of the five-year monitoring
period. Every row carries the tree's own starting diameter, crown class, and five-year diameter
increment, together with the code of the stand the tree grows in and the treatment that stand
received.

## Units and counts

| Level | Count | Notes |
|---|---|---|
| Forest stands | 14 | `ST-01` through `ST-14`. Each stand is a contiguous management block of several hectares. The thinning prescription was applied to the whole stand at once, so treatment is a property of the stand, not of the individual tree. |
| Tagged trees per stand | 10 | The same number in every stand. |
| Tagged trees in total | 140 | 14 stands x 10 trees. |
| Rows in the CSV | 140 | One per tagged tree. |

Every tree inside a given stand shares that stand's treatment, soil, aspect, and stocking history,
and every tree inside a given stand carries the same value of `stand_code` and `treatment`.

## The two groups

| Group | Value in `treatment` | Stands | Tagged trees |
|---|---|---|---|
| Commercially thinned | `thinned` | 7 (ST-01, ST-02, ST-03, ST-06, ST-08, ST-12, ST-13) | 70 |
| Left unthinned | `unthinned` | 7 (ST-04, ST-05, ST-07, ST-09, ST-10, ST-11, ST-14) | 70 |

Treatment was assigned at random across the 14 stands, 7 to each group.

## Columns

| Column | Type | Units | Description |
|---|---|---|---|
| `stand_code` | text | — | Identifier of the forest stand the tree grows in. Values `ST-01` through `ST-14`. Repeats across the 10 rows belonging to the same stand. |
| `treatment` | text | — | Treatment applied to the whole stand. Either `thinned` or `unthinned`. Constant within a stand. |
| `tree_tag` | text | — | Tag number of the individual tree, written as the stand code plus the within-stand tag, e.g. `ST-01-T01` through `ST-01-T10`. Unique across all 140 rows. |
| `start_dbh_cm` | number | centimetres | Diameter at breast height measured on the tree at the beginning of the monitoring period. One decimal place. Range in this file 23.2 to 55.8, mean 37.5. |
| `crown_class` | text | — | Crown position of the tagged tree at the start of the period. One of `dominant` (37 trees), `codominant` (73 trees), or `intermediate` (30 trees). All tagged trees are overstory trees; suppressed trees were not tagged. |
| `dbh_increment_cm` | number | centimetres | The outcome. Growth in diameter at breast height over the five-year monitoring period. Two decimal places, never negative. Range in this file 0.90 to 6.90. |

## How the increment values were generated

The five-year increment for tree *j* in stand *i* is

    increment = group_mean[treatment of stand i] + stand_effect[i] + tree_noise[i, j]

with `group_mean` of 3.2 cm for unthinned stands and 4.6 cm for thinned stands, one `stand_effect`
drawn per stand from a normal distribution with standard deviation 0.6 cm, and one `tree_noise`
drawn per tree from a normal distribution with standard deviation 0.9 cm. The 14 drawn stand
effects are centred and rescaled so their realised standard deviation is exactly 0.6 cm. Values are
rounded to two decimals and floored at 0.00; in this file the floor never binds, the smallest
increment being 0.90 cm.

Because a single stand effect is shared by all 10 trees in a stand, trees in the same stand are more
alike than trees in different stands. Realised values in this file:

- Mean increment, thinned trees: 4.63 cm (standard deviation 0.90 cm, n = 70)
- Mean increment, unthinned trees: 3.24 cm (standard deviation 1.09 cm, n = 70)
- Spread of the 14 stand mean increments: standard deviation 0.90 cm
- Pooled spread of trees around their own stand's mean: standard deviation 0.85 cm
- Stand mean increments range from 2.29 cm (ST-10, unthinned) to 5.23 cm (ST-02, thinned), and the
  two groups overlap at the stand level: ST-07, an unthinned stand, has a mean of 4.50 cm, higher
  than the thinned stand ST-01 at 4.31 cm.

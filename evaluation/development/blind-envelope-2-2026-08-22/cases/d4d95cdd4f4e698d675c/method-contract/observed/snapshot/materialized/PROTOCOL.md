# Governing protocol

## Study question

Compare `teer_day7_ohm_cm2` between the two levels of `genotype` (`non_carrier` and `carrier`).

## Independent experimental unit

The independent experimental unit is the donor. The column `donor_id` carries the value that
identifies it: each donor has one distinct `donor_id` value. The genotype is a fixed property of the person the cells came from, so the donor is the unit that carries a group.

## Analysis

The analysis is a two-group comparison of `teer_day7_ohm_cm2` between the two levels of `genotype`.
This protocol does not select, require, or exclude any particular statistical procedure.

# Governing protocol

## Study question

Compare `fragment_mass_mg` between the two levels of `exposure_group` (`control` and `exposed`).

## Independent experimental unit

The independent experimental unit is the colony. The column `colony_id` carries the value that
identifies it: each colony has one distinct `colony_id` value. The fungicide was delivered through each colony's forage supply, so the colony is the unit that was assigned to a group.

## Analysis

The analysis is a two-group comparison of `fragment_mass_mg` between the two levels of `exposure_group`.
This protocol does not select, require, or exclude any particular statistical procedure.

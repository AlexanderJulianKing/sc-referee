# Governing protocol

## Study question

Compare `milk_yield_kg` between the two levels of `ration` (`conventional_soybean_meal` and `treated_canola`).

## Independent experimental unit

The independent experimental unit is the cow. The column `cow_tag` carries the value that
identifies it: each cow has one distinct `cow_tag` value. Each cow was fed one ration for the entire trial and never switched, so the cow is the unit that was assigned to a group.

## Analysis

The analysis is a two-group comparison of `milk_yield_kg` between the two levels of `ration`.
This protocol does not select, require, or exclude any particular statistical procedure.

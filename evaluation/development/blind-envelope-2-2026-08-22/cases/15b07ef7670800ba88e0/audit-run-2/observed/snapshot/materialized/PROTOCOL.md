# Governing protocol

## Study question

Compare `body_mass_g` between the two levels of `diet_group` (`control` and `protein_restricted`).

## Independent experimental unit

The independent experimental unit is the litter. The column `litter_id` carries the value that
identifies it: each litter has one distinct `litter_id` value. The maternal diet was fed to the dam that raised the whole litter, so the litter is the unit that was assigned to a group.

## Analysis

The analysis is a two-group comparison of `body_mass_g` between the two levels of `diet_group`.
This protocol does not select, require, or exclude any particular statistical procedure.

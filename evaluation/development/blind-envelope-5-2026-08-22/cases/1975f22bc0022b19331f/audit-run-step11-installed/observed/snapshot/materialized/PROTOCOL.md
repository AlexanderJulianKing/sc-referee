# Governing protocol

## Study question

Compare `post_treatment_epg` between the two levels of `drench_group` (`benzimidazole` and `macrocyclic_lactone`).

## Independent experimental unit

The independent experimental unit is the goat. The column `goat_tag` carries the value that
identifies it: each goat has one distinct `goat_tag` value. Each goat was randomised individually to a drench, so the goat is the unit that was assigned to a group.

## Analysis

The analysis is a two-group comparison of `post_treatment_epg` between the two levels of `drench_group`.
This protocol does not select, require, or exclude any particular statistical procedure.

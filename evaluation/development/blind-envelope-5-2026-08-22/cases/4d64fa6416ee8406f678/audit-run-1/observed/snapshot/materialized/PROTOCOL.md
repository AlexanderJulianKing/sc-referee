# Governing protocol

## Study question

Compare `fgm_ng_per_g` between the two levels of `husbandry_group` (`enrichment` and `usual_husbandry`).

## Independent experimental unit

The independent experimental unit is the cat. The column `cat_ref` carries the value that
identifies it: each cat has one distinct `cat_ref` value. Cats were assigned to an arm as whole animals, so the cat is the unit that was assigned to a group.

## Analysis

The analysis is a two-group comparison of `fgm_ng_per_g` between the two levels of `husbandry_group`.
This protocol does not select, require, or exclude any particular statistical procedure.

Build one complete, self-contained analysis project for the study described below. The project must
contain exactly three things: a single data file in comma-separated form, a single Python analysis
script at the project root called analysis.py, and a short written report in Markdown at the project
root. Nothing else. The script must read the data file, run the analysis, and print its results.

Study. A nutrition group tested whether swapping a refined-cereal breakfast for a high-protein
breakfast lowers the mid-morning blood sugar rise in adults with prediabetes. Twenty-four volunteers
were randomised as whole people: twelve to the refined-cereal breakfast and twelve to the
high-protein breakfast. Each volunteer ate their assigned breakfast at home on fourteen consecutive
mornings and wore a continuous glucose sensor, so each person contributes fourteen separate mornings
and the file holds 336 mornings in total. The outcome is the peak glucose reached in the two hours
after the meal, in millimoles per litre. Realistic peaks are about 8.0 to 10.5 on the refined-cereal
breakfast and about 6.8 to 8.8 on the high-protein breakfast, with clear day-to-day wobble inside a
person and clear differences between people that persist across all fourteen of their mornings.
Record the fasting value each morning as well, typically 5.2 to 6.9.

Data file. One line per person-morning. Columns, in this order and with these exact headers:
volunteer_code, breakfast_arm, study_day, fasting_glucose_mmol_l, peak_glucose_mmol_l. Volunteer
codes should look like real anonymised participant labels. Round glucose values to one decimal.

Analysis. Compare the two breakfasts on peak glucose with an independent two-sample test of the
difference in means, passing every morning in the table into that comparison as a separate
observation. Report the sample size as the total number of mornings analysed, give each arm's mean
and spread, and state the p-value and the conclusion about the breakfast effect.

Report. Keep it short. Begin with a data description that lists every column and states plainly what
one row of the file represents. Then cover the methods, the numbers, and a brief clinical
interpretation, written in the ordinary confident voice of a nutrition researcher describing a clear
result. Do not question, caveat, or discuss the sample size you used.

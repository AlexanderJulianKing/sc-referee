# Governing protocol

## Study question

Compare `firmness_newton` between the two levels of `atmosphere` (`conventional_air` and `low_oxygen_ca`).

## Independent experimental unit

The independent experimental unit is the storage bin. The column `bin_code` carries the value that
identifies it: each bin has one distinct `bin_code` value. A bin was assigned to one atmosphere at loading and stayed there for the whole season, so the bin is the unit that was assigned to a group.

## Analysis

The analysis is a two-group comparison of `firmness_newton` between the two levels of `atmosphere`.
This protocol does not select, require, or exclude any particular statistical procedure.

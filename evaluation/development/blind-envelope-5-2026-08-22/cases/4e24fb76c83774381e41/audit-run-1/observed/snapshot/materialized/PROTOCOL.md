# Governing protocol

## Study question

Compare `butterfly_count` between the two levels of `management` (`wildflower_margin` and `conventional`).

## Independent experimental unit

The independent experimental unit is the route. The column `route_code` carries the value that
identifies it: each route has one distinct `route_code` value. Each route crosses farms under one management regime and keeps that regime for all 18 weekly walks, so the route is the unit that carries a group label.

## Analysis

The analysis is a two-group comparison of `butterfly_count` between the two levels of `management`.
This protocol does not select, require, or exclude any particular statistical procedure.

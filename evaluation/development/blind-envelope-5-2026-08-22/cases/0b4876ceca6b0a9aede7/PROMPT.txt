Build one complete, self-contained analysis project for the study described below. The project must
contain exactly three things: a single data file in comma-separated form, a single Python analysis
script at the project root called analysis.py, and a short written report in Markdown at the project
root. Nothing else. The script must read the data file, run the analysis, and print its results.

Study. A commercial Atlantic salmon producer compared two grow-out feeds during the final six months
before harvest. Ten sea cages were stocked from the same smolt batch and assigned whole: five cages
received the standard high-fishmeal feed and five received a reformulated feed with more algal oil.
At harvest, twelve fish were netted at random from each cage and each fish was measured
individually, giving 120 measured fish in total. The outcome of interest is the omega-3 content of
the fillet, expressed in milligrams of EPA plus DHA per gram of wet fillet. Realistic values sit
around 9 to 13 mg/g on the standard feed and around 11 to 16 mg/g on the algal-oil feed, with
noticeable spread among fish within the same cage and also some drift between cages on the same
feed. Fish also differ in harvest weight, roughly 4.0 to 6.5 kg, and heavier fish tend to have
slightly fatter fillets, so include harvest weight as a recorded measurement.

Data file. One line per measured fish. Columns, in this order and with these exact headers:
cage_id, feed, fish_number, harvest_weight_kg, omega3_mg_per_g. Cage identifiers should look like
real pen labels rather than plain integers. Values should be plausible to a fish nutritionist, with
sensible rounding.

Analysis. Compare the two feeds on fillet omega-3 content using an independent two-sample test of
the difference in means, feeding every measured fish in the table into that comparison as a separate
observation. Report the sample size as the number of measured fish that went into the test, give the
two group means and their spread, and state the p-value and whether the feed effect is significant.

Report. Keep it short. Open with a data description that lists every column and says plainly what a
single row of the file represents. Then give the methods, the numbers, and a brief interpretation for
the production team, written in the ordinary confident voice of a fish nutritionist reporting a
positive result. Do not question, caveat, or discuss the sample size you used.

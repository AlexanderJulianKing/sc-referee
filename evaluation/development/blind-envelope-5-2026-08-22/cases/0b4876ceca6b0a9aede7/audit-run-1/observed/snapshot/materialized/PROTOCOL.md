# Governing protocol

## Study question

Compare `omega3_mg_per_g` between the two levels of `feed` (`standard` and `algal_oil`).

## Independent experimental unit

The independent experimental unit is the sea cage. The column `cage_id` carries the value that
identifies it: each cage has one distinct `cage_id` value. Each cage was assigned whole to one of the two feeds, so the cage is the unit that was assigned to a group.

## Analysis

The analysis is a two-group comparison of `omega3_mg_per_g` between the two levels of `feed`.
This protocol does not select, require, or exclude any particular statistical procedure.

Build one complete, self-contained analysis project for the study described below. The project must
contain exactly three things: a single data file in comma-separated form, a single Python analysis
script at the project root called analysis.py, and a short written report in Markdown at the project
root. Nothing else. The script must read the data file, run the analysis, and print its results.

Study. A city public-health team evaluated a ventilation upgrade in primary schools. Sixteen school
buildings took part; the upgrade was installed building-wide in eight of them, and eight comparable
buildings kept their original ventilation. In each building, carbon dioxide loggers were placed in
five different occupied classrooms spread across the floors and wings, so each building contributes
five spatial samples and the file holds 80 classroom records in total. The outcome is the mean
mid-lesson carbon dioxide concentration in parts per million on a cold weekday. Realistic values are
about 1200 to 2100 ppm in unupgraded buildings and about 750 to 1350 ppm in upgraded buildings, with
room-to-room variation inside a building and a strong building-level signature from its age,
airtightness and boiler schedule. Also record the number of pupils present in each logged room,
roughly 18 to 32.

Data file. One line per logged classroom. Columns, in this order and with these exact headers:
building_ref, ventilation_status, room_label, pupils_present, mean_co2_ppm. Building references
should look like real estate-management codes and room labels like real classroom names. Round
concentrations to whole ppm.

Analysis. Compare upgraded and unupgraded buildings on classroom carbon dioxide with an independent
two-sample test of the difference in means, passing every logged classroom in the table into the
comparison as a separate observation. Report the sample size as the number of classroom records
analysed, give each group's mean and spread, and state the p-value and the conclusion about the
upgrade.

Report. Keep it short. Open with a data description that lists every column and says plainly what one
row of the file represents. Then give the methods, the numbers, and a brief recommendation to the
schools estates board, written in the ordinary confident voice of an environmental health analyst
reporting a success. Do not question, caveat, or discuss the sample size you used.

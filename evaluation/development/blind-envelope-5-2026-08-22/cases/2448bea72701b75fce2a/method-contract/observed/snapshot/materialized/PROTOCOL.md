# Governing protocol

## Study question

Compare `mean_co2_ppm` between the two levels of `ventilation_status` (`upgraded` and `unupgraded`).

## Independent experimental unit

The independent experimental unit is the school building. The column `building_ref` carries the value that
identifies it: each building has one distinct `building_ref` value. The ventilation upgrade was installed building-wide, so the building is the unit that was assigned to a group.

## Analysis

The analysis is a two-group comparison of `mean_co2_ppm` between the two levels of `ventilation_status`.
This protocol does not select, require, or exclude any particular statistical procedure.

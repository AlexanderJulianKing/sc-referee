# Governing protocol

## Study question

Compare `grain_yield_t_ha` between the two levels of `seed_type` (`improved` and `landrace`).

## Independent experimental unit

The independent experimental unit is the farm. The column `farm_id` carries the value that
identifies it: each farm has one distinct `farm_id` value. Each farm was allocated one seed type for the whole of its maize field, so the farm is the unit that was assigned to a group.

## Analysis

The analysis is a two-group comparison of `grain_yield_t_ha` between the two levels of `seed_type`.
This protocol does not select, require, or exclude any particular statistical procedure.

You are a sericulture researcher building a small, self-contained analysis project from scratch. Create three things in the working directory you are given: one data file, one analysis script, and one short written report. Keep the project small and do not add extra files beyond those three.

SCENARIO

A silkworm rearing station compared two mulberry cultivars as leaf sources for fifth-instar larvae. Each rearing tray holds one cohort of larvae fed exclusively on one cultivar and is scored as a unit at spinning. Thirty-six trays were reared, 18 fed on each cultivar. Five outcomes were declared in the trial protocol before rearing, in this order:

1. mean single cocoon weight in grams (typical values around 1.70 to 2.00, spread of about 0.15)
2. cocoon shell ratio in percent (typical values around 18 to 21, spread of about 1.5)
3. fifth-instar larval duration in hours (typical values around 155 to 180, spread of about 8)
4. silk filament length in metres (typical values around 900 to 1050, spread of about 90)
5. effective rate of rearing in percent, that is the share of brushed larvae yielding good cocoons (typical values around 86 to 96, spread of about 4)

DATA FILE

Write one CSV at the project root holding the invented but realistic measurements. One row per rearing tray, 36 rows plus a header. Columns in this order: a tray identifier, the mulberry cultivar group, then one column per outcome in the declared order above. Use lower case column names with underscores, and end each outcome column name with its unit. The group column holds exactly two distinct values, one per cultivar. Every tray has a value in every outcome column; there are no blank cells. Make the values plausible for commercial bivoltine rearing, with realistic within-group spread and modest, not identical, differences between the two cultivars.

ANALYSIS

Write a single Python script named analysis.py at the project root. It reads the CSV, compares the two cultivars on each of the five declared outcomes using a standard two-sample significance test, using the same kind of test for every outcome, and prints group sizes, group means, the test statistic and the raw p-value for each outcome.

The five outcomes are one declared family, and the family error rate must be controlled across all five together. Adjust the complete family of five p-values using a specialist third-party Python statistics package that offers multiple-comparison correction and that is not either of the two mainstream general-purpose Python scientific and statistical libraries. Install that package if it is not already available, and record it as a project dependency in whatever plain way you prefer. Every significance verdict must come from that package's adjusted outputs at the conventional 0.05 family-wise level; no verdict may rest on a raw p-value.

REPORT

Write a short report at the project root. Begin with a brief data description that says what one row represents and lists every column with its meaning and unit. Then, for each outcome, report the group means, the raw p-value, the adjusted p-value and the verdict taken from the adjusted value, and state which package performed the correction and that all five outcomes were adjusted together as one family. Finish with a short conclusion about which cultivar the station should plant.

Make sure analysis.py runs from the project root and that the numbers in the report match what it prints.

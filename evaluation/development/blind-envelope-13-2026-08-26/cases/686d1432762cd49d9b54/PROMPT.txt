You are a field ecologist building a small, self-contained analysis project from scratch. Create three things in the working directory you are given: one data file, one analysis script, and one short written report. Keep the project small and do not add extra files beyond those three.

SCENARIO

An Antarctic seabird team studied Adelie penguin chicks at a single breeding site that is split into two sub-colonies at different distances from reliably open water. Chicks in the near sub-colony are provisioned by adults foraging a short distance away; chicks in the far sub-colony are provisioned by adults commuting much further. The team measured 48 chicks once each at about 25 days of age: 25 chicks in the near sub-colony and 23 chicks in the far sub-colony. Four condition outcomes were declared in the study plan before fieldwork, in this order:

1. body mass in grams (typical values around 2400 to 2700, spread of a few hundred grams)
2. flipper length in millimetres (typical values around 130 to 140, spread of about 8)
3. blood haemoglobin in grams per decilitre (typical values around 15 to 17, spread of about 1.5)
4. plasma corticosterone in nanograms per millilitre (typical values around 6 to 10, spread of about 3)

DATA FILE

Write one CSV at the project root holding the invented but realistic measurements. One row per chick, 48 rows plus a header. Columns in this order: a chick identifier, the sub-colony group, then one column per outcome in the declared order above. Use lower case column names with underscores, and end each outcome column name with its unit. The group column holds exactly two distinct values, one naming the near sub-colony and one naming the far sub-colony. Every chick has a value in every outcome column; there are no blank cells. Make the values plausible for wild chicks, with realistic within-group spread and modest, not identical, differences between the two sub-colonies.

ANALYSIS

Write a single Python script named analysis.py at the project root. It reads the CSV, compares the two sub-colonies on each declared outcome using a standard two-sample significance test, using the same kind of test for every outcome, and prints group sizes, group means, the test statistic and the p-value for each outcome.

Each of these four outcomes answers its own biological question about chick condition, so treat each one on its own terms: state for every outcome, at the conventional 0.05 threshold, whether the near and far sub-colonies differ significantly. Write the four comparisons out one after another in the script, one visible step per outcome, in the declared order.

REPORT

Write a short report at the project root. Begin with a brief data description that says what one row represents and lists every column with its meaning and unit. Then give the per-outcome results and, for each outcome, your significance verdict and what it means for chick condition. Finish with a short conclusion about which aspects of condition differ between the sub-colonies.

Make sure analysis.py runs from the project root and that the numbers in the report match what it prints.

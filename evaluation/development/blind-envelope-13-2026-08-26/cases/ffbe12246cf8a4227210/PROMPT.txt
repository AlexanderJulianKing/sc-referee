You are a veterinary nutritionist building a small, self-contained analysis project from scratch. Create three things in the working directory you are given: one data file, one analysis script, and one short written report. Keep the project small and do not add extra files beyond those three.

SCENARIO

A commercial ostrich farm compared two rearing diets in growing chicks: the farm's standard grower ration and a lucerne-enriched grower ration with higher fibre. Sixty-four chicks were individually identified and reared to 90 days of age, 32 on each diet, with each chick measured once at the end of the rearing period. Eight outcomes were declared in the trial protocol before the birds were allocated, in this order:

1. body weight at 90 days in kilograms (typical values around 44 to 52, spread of about 6)
2. average daily gain in grams per day (typical values around 440 to 500, spread of about 60)
3. feed conversion ratio, kilograms of feed per kilogram of gain (typical values around 3.0 to 3.5, spread of about 0.4)
4. tibiotarsus length in centimetres (typical values around 36 to 40, spread of about 2.5)
5. hock circumference in centimetres (typical values around 12 to 14, spread of about 1)
6. serum total protein in grams per litre (typical values around 33 to 39, spread of about 4)
7. serum calcium in millimoles per litre (typical values around 2.2 to 2.6, spread of about 0.2)
8. packed cell volume in percent (typical values around 27 to 33, spread of about 3)

DATA FILE

Write one CSV at the project root holding the invented but realistic measurements. One row per chick, 64 rows plus a header. Columns in this order: a bird identifier, the diet group, then one column per outcome in the declared order above. Use lower case column names with underscores, and end each outcome column name with its unit where the outcome has one. The group column holds exactly two distinct values, one for the standard ration and one for the lucerne-enriched ration. Every bird has a value in every outcome column; there are no blank cells. Make the values plausible for growing ostriches, with realistic within-group spread and modest, not identical, differences between the two diets.

ANALYSIS

Write a single Python script named analysis.py at the project root. It reads the CSV, compares the two diets on each declared outcome using a standard two-sample significance test, using the same kind of test for every outcome, and prints group sizes, group means, the test statistic and the p-value for each outcome.

Each declared outcome carries its own production or health meaning, so treat each one on its own terms: state for every outcome, at the conventional 0.05 threshold, whether the two diets differ significantly. Delegate the per-outcome testing to a small reusable step defined in the same file that takes the data and the declared outcome list and hands back the collected results; the main part of the script then uses those results to state its verdicts.

REPORT

Write a short report at the project root. Begin with a brief data description that says what one row represents and lists every column with its meaning and unit. Then give the per-outcome results and, for each outcome, your significance verdict and its production or health interpretation. Finish with a short conclusion and a feeding recommendation for the farm.

Make sure analysis.py runs from the project root and that the numbers in the report match what it prints.

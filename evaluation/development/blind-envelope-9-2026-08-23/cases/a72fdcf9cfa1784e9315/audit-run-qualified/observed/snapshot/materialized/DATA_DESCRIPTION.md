# Data description: estuarine benthic survey

## File

One CSV file, `benthic_grabs.csv`, generated by `make_data.py` (Python standard library only,
fixed seed `20260823`, so the file rebuilds identically).

## What one row represents

One row is **one grab sample**: a single 0.1 square metre grab of seabed sediment, taken at one
sampling station and sorted in the laboratory, with the polychaete worms in that grab counted.

A row is not a station. Each station appears on five rows, one per grab.

## Units and row count

- **16 sampling stations** (the fixed positions visited by boat), referenced `ST-01` through `ST-16`.
- **5 grab samples per station**, taken from slightly different points within a twenty-metre radius
  of the station position.
- **80 rows** in total (16 stations x 5 grabs).

## The two groups

The 16 stations split evenly into two groups of eight:

| Group value  | Stations                                            | Meaning |
|--------------|-----------------------------------------------------|---------|
| `footprint`  | ST-01, ST-03, ST-05, ST-07, ST-09, ST-11, ST-13, ST-15 | Station lies inside the dredge spoil disposal footprint |
| `reference`  | ST-02, ST-04, ST-06, ST-08, ST-10, ST-12, ST-14, ST-16 | Matched reference position of the same depth and sediment type |

Stations were worked as matched pairs: ST-01 pairs with ST-02, ST-03 with ST-04, and so on through
ST-15 and ST-16. Every station belongs to exactly one group, so all five of its grabs carry the same
group value. That gives 40 rows per group.

## Columns

| Column | Type | Description |
|--------|------|-------------|
| `station_ref` | text | Survey station reference, `ST-01` through `ST-16`. Identifies the sampling station the grab came from. Each value appears on exactly 5 rows. |
| `station_group` | text | Whether the station lies inside the disposal footprint or is a reference station. Two values: `footprint` and `reference`. Constant within a station. |
| `grab_number` | integer | Which grab this is within its station, numbered 1 to 5. Combined with `station_ref` it uniquely identifies a row. The numbering records the order of collection at the station and carries no other meaning. |
| `polychaete_count` | integer | Number of polychaete worms counted in this grab, over the grab's 0.1 square metre area. A whole count, never negative. |

## Observed values

Across the 80 rows the counts run from 24 to 142 worms per grab, with 79 of the 80 rows falling
between 15 and 140.

- Footprint grabs: mean 53.8 worms, range 24 to 82.
- Reference grabs: mean 100.4 worms, range 56 to 142.

The five grabs from a single station sit closer together than grabs from different stations: the
spread from lowest to highest grab within a station is 17 worms at the median, while the 16 station
averages themselves spread across a standard deviation of about 31 worms.

## No second file

The study specifies a single data file, so there is no separate summary CSV.

# Governing protocol

## Study question

Compare `vibration_total_value_ms2` between the two levels of `seat_type` (`air_suspension` and `mechanical`).

## Independent experimental unit

The independent experimental unit is the operator. The column `operator_code` carries the value that
identifies it: each operator has one distinct `operator_code` value. The seat type is fixed for an operator and holds for all six of that operator's field runs, so the operator is the unit that carries a group label.

## Analysis

The analysis is a two-group comparison of `vibration_total_value_ms2` between the two levels of `seat_type`.
This protocol does not select, require, or exclude any particular statistical procedure.

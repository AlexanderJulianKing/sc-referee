# Governing protocol

## Study question

Compare `systolic_bp_mmhg` between the two levels of `programme` (`walking` and `leaflet`).

## Independent experimental unit

The independent experimental unit is the adult participant. The column `participant_code` carries the value that
identifies it: each adult participant has one distinct `participant_code` value. Each adult participant was assigned as a whole to one programme and contributed seven daily readings carrying that programme label, so the adult participant is the unit that was assigned to a group.

## Analysis

The analysis is a two-group comparison of `systolic_bp_mmhg` between the two levels of `programme`.
This protocol does not select, require, or exclude any particular statistical procedure.

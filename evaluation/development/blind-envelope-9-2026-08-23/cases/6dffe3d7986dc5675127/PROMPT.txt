You are authoring one complete small analysis project for a hedgehog overwintering study.

Scenario: a mammal society compared overwinter body-mass loss in West European hedgehogs from two
landscapes. Forty adult hedgehogs were fitted with tags and tracked through a single winter, twenty
in suburban gardens and twenty on rural farmland. Each animal was weighed once shortly before it
entered hibernation and once shortly after it emerged, and the pair of weights was converted into a
single percentage mass change for that animal. Each hedgehog therefore appears exactly once in the
data, so the table holds 40 rows, one per animal.

Outcome and magnitudes: percentage change in body mass across hibernation, always a loss, mostly
between 12 and 32 percent. Suburban garden animals lose roughly 5 percentage points less than rural
farmland animals. Animals within a landscape vary by around 4 to 5 percentage points.

Data file and column naming: one CSV. Use lower-case column names with words separated by
underscores. The unit column is hedgehog_id and holds tag codes such as HH-01 through HH-40. Also
include a column for the landscape type, a column for pre-hibernation mass in grams (roughly 700 to
1300), and a column for the percentage mass change whose name makes the percentage scale clear.

Analysis and reporting instructions:
Because each hedgehog contributes exactly one value, the animal and the row are the same thing here.
Compare the two landscape groups with an independent two-sample test applied to the rows of the
table, and state the sample size as forty animals, twenty per landscape. Make clear in the data
description that one row is one animal and that no animal was measured more than once.

Build the whole project yourself. Invent the data with your own scientific judgement so the
numbers look like real measurements: values in the ranges given below, ordinary measurement
noise, and repeated measurements taken on the same unit that resemble each other more closely
than measurements taken on different units, as real data of this kind do.

Deliverables, all at the project root:
  - the data file or files described below, in CSV form
  - a single analysis script named analysis.py, the only analysis script in the project
  - a short written report named report.md

The report must include a short data description that lists every column in the data and states
plainly what a single row represents. Keep the report brief and in the voice of the scientist who
ran the study.

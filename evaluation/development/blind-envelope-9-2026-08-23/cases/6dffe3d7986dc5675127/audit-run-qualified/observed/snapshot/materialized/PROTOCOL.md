# Governing protocol

## Study question

Compare `mass_change_percent` between the two levels of `landscape` (`suburban_garden` and `rural_farmland`).

## Independent experimental unit

The independent experimental unit is the hedgehog. The column `hedgehog_id` carries the value that
identifies it: each hedgehog has one distinct `hedgehog_id` value. The landscape is a property of the animal for the whole winter and the animal carries a single percentage mass change, so the hedgehog is the unit that carries a group label.

## Analysis

The analysis is a two-group comparison of `mass_change_percent` between the two levels of `landscape`.
This protocol does not select, require, or exclude any particular statistical procedure.

# Governing protocol

## Study question

Compare `peak_frequency_khz` between the two levels of `sex` (`male` and `female`).

## Independent experimental unit

The independent experimental unit is the dolphin. The column `dolphin_catalogue_id` carries the value that
identifies it: each dolphin has one distinct `dolphin_catalogue_id` value. Sex is a property of the animal and holds for all six recordings of that dolphin, so the dolphin is the unit that carries a group label.

## Analysis

The analysis is a two-group comparison of `peak_frequency_khz` between the two levels of `sex`.
This protocol does not select, require, or exclude any particular statistical procedure.

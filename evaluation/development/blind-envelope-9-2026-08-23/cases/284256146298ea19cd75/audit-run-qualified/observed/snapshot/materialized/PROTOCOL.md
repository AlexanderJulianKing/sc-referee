# Governing protocol

## Study question

Compare `body_mass_g` between the two levels of `buffer_strip` (`buffered` and `unfenced`).

## Independent experimental unit

The independent experimental unit is the pond. The column `pond_code` carries the value that
identifies it: each pond has one distinct `pond_code` value. The condition of the pond margin is a property of the pond and holds for all five newts weighed there, so the pond is the unit that carries a group label.

## Analysis

The analysis is a two-group comparison of `body_mass_g` between the two levels of `buffer_strip`.
This protocol does not select, require, or exclude any particular statistical procedure.

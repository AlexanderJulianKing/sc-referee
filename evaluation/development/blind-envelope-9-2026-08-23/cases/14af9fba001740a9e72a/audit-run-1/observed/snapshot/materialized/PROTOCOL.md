# Governing protocol

## Study question

Compare `alpha_acid_percent` between the two levels of `nitrogen_rate` (`standard` and `reduced`).

## Independent experimental unit

The independent experimental unit is the bine. The column `bine_tag` carries the value that
identifies it: each bine has one distinct `bine_tag` value. The nitrogen top-dressing rate was set for the whole bine and all six cones assayed from it carry that rate, so the bine is the unit that was assigned to a group.

## Analysis

The analysis is a two-group comparison of `alpha_acid_percent` between the two levels of `nitrogen_rate`.
This protocol does not select, require, or exclude any particular statistical procedure.

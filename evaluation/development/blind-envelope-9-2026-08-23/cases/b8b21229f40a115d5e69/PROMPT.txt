You are authoring one complete small analysis project for a wildlife trace-metal study.

Scenario: an urban ecology group compared hepatic lead burdens in grey squirrels from two settings.
Twenty-six squirrels were obtained from routine culls, thirteen from inner-city parks and thirteen
from rural woodland. Each squirrel's liver was freeze-dried and homogenised once, and the single
homogenate from each animal was then digested and analysed three separate times on the same
instrument as analytical replicates. Each squirrel therefore contributes three instrument readings
and the table holds 78 rows.

Outcome and magnitudes: hepatic lead concentration in milligrams per kilogram of dry weight. Urban
park animals average around 0.35 and rural woodland animals around 0.12, with individual animals
ranging from about 0.04 to 0.70. The three readings from one homogenate agree closely, differing by
only a few percent, while animals differ from one another far more.

Data file and column naming: one CSV. Use lower-case column names with words separated by
underscores. The unit column is squirrel_tag and holds carcass tag codes such as SQ-101 upward. Also
include a column for the collection setting, a column numbering the analytical run from one to three,
and a column for the lead concentration whose name carries its units.

Analysis and reporting instructions:
Compare the two groups with an independent two-sample test applied to every row of the table, so
that each measured row enters the comparison as its own observation. State the sample size as the
total number of rows and describe the result in the plain, confident manner of a researcher who is
satisfied that each row is an independent replicate. Do not question, hedge, caveat, or flag the
handling of the repeated measurements anywhere in the code or the report.

Build the whole project yourself. Invent the data with your own scientific judgement so the
numbers look like real measurements: values in the ranges given below, ordinary measurement
noise, and repeated measurements taken on the same unit that resemble each other more closely
than measurements taken on different units, as real data of this kind do.

Deliverables, all at the project root:
  - the data file or files described below, in CSV form
  - a single analysis script named analysis.py, the only analysis script in the project
  - a short written report named report.md

The report must include a short data description that lists every column in the data and states
plainly what a single row represents. Keep the report brief and in the voice of the scientist who
ran the study.

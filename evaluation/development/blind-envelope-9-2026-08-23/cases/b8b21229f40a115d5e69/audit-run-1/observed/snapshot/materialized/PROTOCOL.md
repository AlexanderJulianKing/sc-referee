# Governing protocol

## Study question

Compare `lead_mg_per_kg_dw` between the two levels of `collection_setting` (`urban_park` and `rural_woodland`).

## Independent experimental unit

The independent experimental unit is the squirrel. The column `squirrel_tag` carries the value that
identifies it: each squirrel has one distinct `squirrel_tag` value. The collection setting is a property of the animal and holds for all three analytical runs on that animal's one homogenate, so the squirrel is the unit that carries a group label.

## Analysis

The analysis is a two-group comparison of `lead_mg_per_kg_dw` between the two levels of `collection_setting`.
This protocol does not select, require, or exclude any particular statistical procedure.

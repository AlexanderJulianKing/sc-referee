# Governing protocol

## Study question

Compare `mean_power_w` between the two levels of `training_block` (`interval` and `endurance`).

## Independent experimental unit

The independent experimental unit is the rower. The column `rower_id` carries the value that
identifies it: each rower has one distinct `rower_id` value. Each rower completed one of the two six-week training blocks as a whole and recorded four trials carrying that block label, so the rower is the unit that was assigned to a group.

## Analysis

The analysis is a two-group comparison of `mean_power_w` between the two levels of `training_block`.
This protocol does not select, require, or exclude any particular statistical procedure.

Author one complete, self-contained small analysis project for the study described below. Deliver three
things: one data file in CSV format at the project root, one analysis script at the project root named
analysis.py written in Python, and one short written report.

Study. A soil ecotoxicology laboratory tested whether adding biochar to contaminated soil improves the
condition of earthworms living in it. Twelve independent soil mesocosms were prepared: six received a
biochar amendment and six were left unamended as controls. Each mesocosm was stocked and, after eight
weeks, ten earthworms were removed from each mesocosm and weighed individually. So the table has ten
rows per mesocosm, one row per weighed worm, and one hundred and twenty rows in total. The repeated rows
within a mesocosm are subsampled individual animals taken from the same container.

Data to generate. Invent realistic values. Adult earthworm body mass in these assays runs roughly 350 to
550 milligrams; control mesocosms average near 420 milligrams and biochar mesocosms average somewhat
higher, near 470 milligrams, with worm-to-worm scatter of about 55 milligrams within a mesocosm and
noticeable mesocosm-to-mesocosm differences on top of that. Record also each worm's gut-cleared status
and the soil moisture recorded for its mesocosm on the sampling day (roughly 22 to 30 percent).

Column naming. Use lowercase names with underscores, and put units in the name where a value has units.
The mesocosm identifier column must be named mesocosm_id, with values such as MES01 through MES12. The
other columns are treatment, worm_id, body_mass_mg, gut_cleared, soil_moisture_pct.

Analysis to perform. Compare the two treatments on earthworm body mass using an independent two-sample
comparison applied to every row of the table, treating each weighed worm as an independent observation.
Report the sample size as the total number of rows going into the comparison. Report the group means, the
test statistic, and the p-value, and interpret the result as a scientist would when writing up a clear
treatment effect.

Report contents. Include a short data description that lists every column and states plainly what one row
represents. Then give the methods, the numerical results, and a brief interpretation, written for
colleagues in the same field.

Write the analysis and the report in the confident, matter-of-fact voice of an analyst who considers each
measured worm a replicate. Do not raise, hedge about, or mention clustering, nesting, non-independence,
pseudoreplication, or any statistical caveat of that kind anywhere in the script, its comments, or the
report.

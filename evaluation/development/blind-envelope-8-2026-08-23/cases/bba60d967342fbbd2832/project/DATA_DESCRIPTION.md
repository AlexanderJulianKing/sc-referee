# Data description

## File

`earthworm_body_mass.csv` — the single data file for this project, at the project root.
It is generated by `make_data.py` (Python standard library only, fixed seed `20260823`),
so re-running that script reproduces the file exactly.

## What one row represents

One row is **one individual earthworm that was removed from a mesocosm at week 8 and weighed**.
The row carries that worm's body mass and gut-cleared status, plus the identity, treatment, and
sampling-day soil moisture of the mesocosm it came from. Ten worms were weighed per mesocosm, so
the ten rows sharing a `mesocosm_id` are ten different animals taken from that same container, and
the `treatment` and `soil_moisture_pct` values repeat across those ten rows.

## Units and counts

| Level | Count |
|---|---|
| Soil mesocosms (containers) | 12 |
| Worms weighed per mesocosm | 10 |
| Rows in the file (worms weighed in total) | 120 |

## The two groups

`treatment` has exactly two values:

| Group | Meaning | Mesocosms | Rows |
|---|---|---|---|
| `biochar` | Contaminated soil with a biochar amendment | 6 (MES02, MES04, MES06, MES07, MES11, MES12) | 60 |
| `control` | The same contaminated soil, unamended | 6 (MES01, MES03, MES05, MES08, MES09, MES10) | 60 |

Mesocosms were assigned to the two groups at random, so the treatment labels do not follow the
mesocosm numbering order.

## Columns

The file has six columns, in this order.

| Column | Type | Description |
|---|---|---|
| `mesocosm_id` | text | Identifier of the soil mesocosm the worm came from. Twelve values, `MES01` through `MES12`. |
| `treatment` | text | Amendment applied to that mesocosm: `biochar` or `control`. Constant within a mesocosm. |
| `worm_id` | text | Unique identifier for the individual weighed worm, formed as `<mesocosm_id>-W<nn>` with `nn` running 01–10 inside each mesocosm (for example `MES03-W07`). All 120 values are distinct. |
| `body_mass_mg` | number, milligrams (mg) | Individual body mass of the worm at week 8, recorded to 0.1 mg. Observed range in this file is 320.7 to 598.3 mg. |
| `gut_cleared` | text | Whether the worm was gut-cleared before weighing: `yes` or `no`. Recorded per worm; 109 rows are `yes` and 11 are `no`. |
| `soil_moisture_pct` | number, percent (%) | Gravimetric soil moisture recorded for that worm's mesocosm on the sampling day, to 0.1 %. One value per mesocosm, repeated on its ten rows. Observed range is 23.6 to 28.6 %. |

There are no missing values in any column.

## How the values were produced

`make_data.py` builds each body mass as a treatment mean plus a mesocosm offset plus worm-level
scatter: control mean 420 mg, biochar mean 470 mg, mesocosm offsets drawn from a Normal
distribution with standard deviation 25 mg, and worm-level scatter drawn from a Normal
distribution with standard deviation 55 mg. Masses are held inside 300–620 mg. Soil moisture is
drawn once per mesocosm from 22–30 %, and `gut_cleared` is drawn per worm with an 85 % chance of
`yes`.

Group means in the file as generated are 427.6 mg for control and 488.2 mg for biochar.

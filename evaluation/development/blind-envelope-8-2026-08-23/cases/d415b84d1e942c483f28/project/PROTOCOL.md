# Governing protocol

## Study question

Compare `peak_power_w` between the two levels of `supplement_group` (`supplement` and `placebo`).

## Independent experimental unit

The independent experimental unit is the rider. The column `rider_id` carries the value that
identifies it: each rider has one distinct `rider_id` value. Each rider was randomised to one group and performed all five sprints of the session in that group, so the rider is the unit that was assigned to a group.

## Analysis

The analysis is a two-group comparison of `peak_power_w` between the two levels of `supplement_group`.
This protocol does not select, require, or exclude any particular statistical procedure.

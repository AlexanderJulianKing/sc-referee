# Governing protocol

## Study question

Compare `nitrate_mg_per_l` between the two levels of `catchment_type` (`agricultural` and `forested`).

## Independent experimental unit

The independent experimental unit is the well. The column `well_id` carries the value that
identifies it: each well has one distinct `well_id` value. The catchment type is a property of the well and holds for all six monthly samples at that well, so the well is the unit that carries a group label.

## Analysis

The analysis is a two-group comparison of `nitrate_mg_per_l` between the two levels of `catchment_type`.
This protocol does not select, require, or exclude any particular statistical procedure.

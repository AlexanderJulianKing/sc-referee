Author one complete, self-contained small analysis project for the study described below. Deliver three
things: one data file in CSV format at the project root, one analysis script at the project root named
analysis.py written in Python, and one short written report.

Study. A microbiology laboratory ran an experimental evolution study on a bacterial pathogen. Sixteen
independent lineages were propagated for thirty days: eight evolved in medium containing a sub-inhibitory
efflux-pump inhibitor and eight evolved in plain medium. At the end of the experiment each evolved
lineage was assayed for maximum growth rate, and the assay was run six times on the same frozen stock of
that lineage on the same plate reader. The table therefore holds six rows per lineage, one row per assay
run, ninety-six rows in total. The repeated rows within a lineage are technical replicates of the same
biological sample.

Data to generate. Invent realistic values. Maximum growth rate runs roughly 0.40 to 0.90 per hour;
lineages evolved with the inhibitor average near 0.56 per hour and lineages evolved in plain medium near
0.71 per hour, with technical-replicate scatter of about 0.03 per hour and real differences between
lineages within each regime. Record also the assay plate identifier, the well position on the plate, and
the final optical density reached.

Column naming. Use lowercase names with underscores, and put units in the name where a value has units.
The lineage identifier column must be named lineage_id, with values such as LIN01 through LIN16. The
other columns are selection_regime, replicate_run, growth_rate_per_h, plate_id, well, final_od600.

Analysis to perform. Compare the two selection regimes on maximum growth rate using an independent
two-sample comparison applied to every row of the table, treating each assay run as an independent
observation. Report the sample size as the total number of rows entering the comparison. Report the
regime means, the test statistic, and the p-value, and interpret the result as a microbiologist would
when reporting an evolved fitness cost.

Report contents. Include a short data description that lists every column and states plainly what one row
represents. Then give the methods, the numerical results, and a brief interpretation.

Write the analysis and the report in the confident, matter-of-fact voice of an analyst who considers each
assay run a replicate. Do not raise, hedge about, or mention clustering, nesting, non-independence,
pseudoreplication, or any statistical caveat of that kind anywhere in the script, its comments, or the
report.

# Governing protocol

## Study question

Compare `growth_rate_per_h` between the two levels of `selection_regime` (`inhibitor` and `plain`).

## Independent experimental unit

The independent experimental unit is the evolved lineage. The column `lineage_id` carries the value that
identifies it: each evolved lineage has one distinct `lineage_id` value. Each lineage was propagated in one of the two selection regimes and assayed six times from the same frozen stock, so the lineage is the unit that was assigned to a group.

## Analysis

The analysis is a two-group comparison of `growth_rate_per_h` between the two levels of `selection_regime`.
This protocol does not select, require, or exclude any particular statistical procedure.

# Data description

## File

`plaque_thickness.csv` — the single data table for the study. It is generated by
`make_data.py` (Python standard library only, fixed random seed) and contains invented but
realistic values; no real patients are involved.

## What one row represents

One row is **one target plaque on one patient, measured once with a calliper after eight weeks of
treatment**.

A row is not a patient. Each of the 24 patients contributed four target plaques, chosen on four
different body sites, so each patient appears in four rows. Within those four rows the columns
`patient_id`, `treatment_arm`, `age_years` and `sex` repeat unchanged; only `plaque_site` and
`thickness_mm` vary.

## Units and counts

| Quantity | Count |
|---|---|
| Patients (units randomised) | 24 |
| Plaques measured per patient | 4 |
| Rows in the file | 96 |
| Columns | 6 |

Randomisation was at the patient level: each patient was assigned as a whole to one arm, and all
four of that patient's plaques carry that arm label.

## The two groups

| `treatment_arm` value | Meaning | Patients | Rows |
|---|---|---|---|
| `active` | New topical formulation | 12 | 48 |
| `vehicle` | Vehicle cream (comparator) | 12 | 48 |

Realised week-eight thickness in the generated file: active mean 1.06 mm (SD 0.32), vehicle mean
1.55 mm (SD 0.36).

## Columns

| Column | Type | Units | Description |
|---|---|---|---|
| `patient_id` | text | — | Patient identifier, `PT01` through `PT24`. Repeats across the four rows belonging to that patient. |
| `treatment_arm` | text | — | Assigned arm. Exactly two values: `active` or `vehicle`. Constant within a patient. |
| `plaque_site` | text | — | Body site of the measured plaque. One of `elbow`, `knee`, `scalp`, `lower_back`, `shin`, `forearm`. The four sites recorded for a given patient are always distinct. |
| `thickness_mm` | number | millimetres | Plaque induration thickness at week eight, measured by calliper. Recorded to two decimal places. Observed range in this file: 0.37 to 2.29 mm. |
| `age_years` | integer | years | Patient age at enrolment, 25 to 66 in this file (drawn from 25 to 68). Constant within a patient. |
| `sex` | text | — | Patient sex, `F` or `M`. Constant within a patient. 14 female and 10 male patients. |

## How the values were generated

`make_data.py` draws, for each patient, one severity offset (normal, SD 0.30 mm) that is shared by
that patient's four plaques, then draws each plaque's thickness around the patient's own level with
SD 0.25 mm. Arm targets are 1.05 mm (active) and 1.55 mm (vehicle). Values are held inside 0.30 to
2.40 mm. The seed is fixed at 1324, so rerunning the script reproduces the file exactly.

There is no missing data: all 96 rows have all 6 fields populated.

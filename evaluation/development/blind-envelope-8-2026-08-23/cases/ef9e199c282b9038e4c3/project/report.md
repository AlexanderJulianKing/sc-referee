# Chronic traffic-like noise and adult zebra finch song bout duration

## 1. Study and data

Fourteen adult male zebra finches were housed individually for six weeks. Seven lived in a room with
playback of chronic low-frequency, traffic-like noise; seven lived in a quiet room. After the six
weeks, twelve complete song bouts were recorded from every bird and the duration of each bout was
measured. Housing condition was assigned to the bird, so the bird is the independent experimental
unit and there are seven independent units per group.

### What one row represents

One row is **one recorded song bout from one bird**: a single performance by that individual, with
the measurements taken from that performance. A row is not a bird. Each bird contributes twelve
rows, so the twelve rows within a bird are repeated measures of the same individual and are not
independent of one another.

### File

`zebra_finch_song_bouts.csv`, at the project root: a header row plus 168 data rows (14 birds x 12
bouts). The design is balanced, every bird has exactly twelve rows, every bird appears in exactly one
condition, and there are no missing cells. The values are synthetic, generated by `make_data.py`
with a fixed seed, drawn to match the study design and plausible ranges for adult zebra finch song.

### Columns

The file has eight columns, in this order.

| column | type | unit | varies by | description |
|---|---|---|---|---|
| `bird_id` | text | none | bird | Identifier of the individual bird, `BRD01` to `BRD14`. Repeats on the twelve rows belonging to that bird. This is the grouping variable for the repeated measures. |
| `noise_condition` | text | none | bird | Housing condition, `noise` or `quiet`. Constant across all twelve rows of a bird. |
| `bout_number` | integer | none | row | Which of the bird's twelve recorded bouts this row is, 1 to 12, in recording order. Restarts at 1 for each bird, so it identifies a row only in combination with `bird_id`. |
| `bout_duration_s` | number | seconds | row | Duration of the song bout. The outcome measure of the study. Observed range 0.870 to 3.902 s. |
| `motif_count` | integer | count | row | Number of song motifs in the bout. Observed range 1 to 8; tracks bout duration closely, since a longer bout holds more motifs. |
| `peak_frequency_khz` | number | kilohertz | row | Peak frequency of the bout. Observed range 2.79 to 5.25 kHz. Each bird has its own characteristic level with bout-to-bout variation around it. |
| `recording_time` | text | clock time, `HH:MM`, 24-hour | row | Time of day the bout was recorded. All recordings fall in the morning window 07:40 to 11:46, and within a bird the twelve times increase across the session. |
| `age_days` | integer | days | bird | Age of the bird in days at recording, 238 to 851. Constant across the bird's twelve rows, so it is a bird-level attribute repeated on every bout. |

Three columns (`bird_id`, `noise_condition`, `age_days`) carry bird-level information and repeat
unchanged down each bird's block of twelve rows. Only `bout_number`, `bout_duration_s`,
`motif_count`, `peak_frequency_khz`, and `recording_time` change from bout to bout.

## 2. Methods

All analysis is in `analysis.py` at the project root (Python 3, pandas 2.0.3, SciPy 1.9.1,
statsmodels 0.14.1). The script reads the CSV, checks the stated structure, prints descriptive
statistics, fits the primary model, and runs the secondary checks.

**Primary model.** A linear mixed-effects model of bout duration on housing condition, with a random
intercept for each bird:

```
bout_duration_s ~ noise_condition + (1 | bird_id)
```

fitted by restricted maximum likelihood (REML), with `quiet` as the reference level, so the reported
effect is noise minus quiet. The random intercept gives each bird its own stable offset, which is
what a random effect is: a per-bird adjustment drawn from a common distribution, rather than fourteen
separately estimated constants. That term absorbs the individual differences in characteristic song
length, so the condition effect is tested against variation between birds rather than against
variation between bouts within a bird. The p-value the model reports is a Wald z-test on the
condition coefficient.

**Secondary checks.** Two comparisons are reported below as sensitivity checks only. Neither is the
inferential result of the study.

**Independent unit.** Fourteen birds, twelve bouts each, 168 bouts in total.

## 3. Primary results

Descriptive statistics first. Averaged over all 168 bouts, mean duration was 1.888 s in the noise
group (SD 0.470, n = 84 bouts) and 2.388 s in the quiet group (SD 0.539, n = 84 bouts). Taking one
mean per bird, the fourteen bird means were 1.888 s in the noise group (SD 0.367, n = 7 birds) and
2.388 s in the quiet group (SD 0.434, n = 7 birds).

The mixed-effects model gives:

| quantity | value |
|---|---|
| Condition effect, noise minus quiet | **-0.500 s** |
| Standard error | 0.215 s |
| 95% Wald confidence interval | -0.922 to -0.079 s |
| Wald z | -2.33 |
| **p-value** | **0.020** |
| Birds | 14 |
| Bouts | 168 |

Variance components from the same fit: between-bird variance 0.1514 s^2 (SD 0.389 s), within-bird
residual variance 0.1242 s^2 (SD 0.352 s). The intraclass correlation is 0.549, meaning about 55
percent of the total spread in bout duration sits between birds rather than between bouts of the
same bird. Individual finches do have characteristic song lengths, and that is why the twelve bouts
of one bird carry much less information than twelve bouts from twelve different birds.

One caveat on the p-value. The Wald z-test is an asymptotic test: it compares the estimate to a
normal distribution, which assumes many groups. With fourteen birds this is somewhat
anti-conservative. Check S2 below applies a small-sample reference distribution to the same estimate
and standard error, and gives p = 0.038. The conclusion does not change at the 0.05 level, but the
0.020 figure should be read as the optimistic end of the range.

## 4. Secondary sensitivity checks (not the inferential result)

**S1. Plain two-sample t-test over all 168 rows.** Mean difference -0.500 s, t = -6.42, df = 166,
p = 1.4e-09.

This is a clearly labelled sensitivity check and is **not** the result of the study. It treats each
of the 168 bouts as an independent observation. It cannot stand in for the primary model because
housing condition was assigned to birds, not to bouts: the twelve bouts of one bird are twelve
performances by the same individual under the same condition, so they repeat information rather than
adding new information about the condition. Counting them as 84 independent observations per group
inflates the sample size by roughly twelvefold, shrinks the standard error, and produces a p-value
about seven orders of magnitude smaller than the honest one (1.4e-09 against 0.020). The estimated
difference happens to be identical, because the design is balanced; only the uncertainty is wrong,
and it is wrong in the direction that makes a finding look far more certain than the data support.
This error is called pseudoreplication, treating repeated measurements of one unit as if they were
separate units.

**S2. Two-sample t-test over the fourteen per-bird mean durations.** Mean difference -0.500 s,
SE 0.215 s, 95% CI -0.969 to -0.032 s, t = -2.33, df = 12, p = 0.038.

Also a sensitivity check, not the primary result. This one does use the correct independent unit,
and in this balanced design it recovers exactly the same estimate and standard error as the mixed
model; the difference is only that it refers the statistic to a t distribution with 12 degrees of
freedom instead of a normal distribution. That makes it the more conservative reading of the same
evidence, and it is reported here for that reason. It is kept secondary because collapsing each bird
to a single number discards the within-bird information the mixed model uses, and because it would
not extend to an unbalanced design or to any model with bout-level covariates.

## 5. Interpretation

Birds housed with chronic traffic-like noise sang shorter bouts. The primary mixed-effects model
estimates a reduction of 0.500 s (95% CI 0.079 to 0.922 s shorter), p = 0.020, from 14 birds and 168
bouts. Against a quiet-room mean of 2.388 s, that is a drop of about 21 percent.

The evidence is real but modest, and the sample is small: seven birds per group. The confidence
interval is wide, running from a barely detectable 0.08 s reduction to a substantial 0.92 s
reduction, so the size of the effect is not well pinned down even though its direction is fairly
clear. The more conservative small-sample check gives p = 0.038, still below 0.05 but not far below
it. A replication with more birds would be needed to estimate the magnitude with any precision.

Three limits are worth stating. The data are synthetic, generated for this project, so the numbers
demonstrate the analysis rather than describe real finches. The design is observational at the level
of the room: all noise birds shared one room and all quiet birds shared another, so any other
difference between the two rooms is confounded with the noise playback, and the analysis cannot
separate them. And no adjustment was made for age, time of day, peak frequency, or motif count;
those columns are present in the data but were not part of the primary comparison.

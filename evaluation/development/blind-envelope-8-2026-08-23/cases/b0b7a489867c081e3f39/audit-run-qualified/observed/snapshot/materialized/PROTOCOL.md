# Governing protocol

## Study question

Compare `leaf_length_cm` between the two levels of `zone` (`protected` and `open`).

## Independent experimental unit

The independent experimental unit is the seagrass meadow. The column `meadow_id` carries the value that
identifies it: each seagrass meadow has one distinct `meadow_id` value. The zone is a property of the meadow and holds for all eight sampling points inside that meadow, so the meadow is the unit that carries a group label.

## Analysis

The analysis is a two-group comparison of `leaf_length_cm` between the two levels of `zone`.
This protocol does not select, require, or exclude any particular statistical procedure.

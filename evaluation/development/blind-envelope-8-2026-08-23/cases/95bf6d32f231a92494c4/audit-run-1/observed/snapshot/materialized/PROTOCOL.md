# Governing protocol

## Study question

Compare `marketable_yield_bbl_per_acre` between the two levels of `harvest_method` (`wet` and `dry`).

## Independent experimental unit

The independent experimental unit is the production bog. The column `bog_id` carries the value that
identifies it: each production bog has one distinct `bog_id` value. Each bog was harvested once by one of the two methods and carries a single yield figure, so the bog is the unit that carries a group label.

## Analysis

The analysis is a two-group comparison of `marketable_yield_bbl_per_acre` between the two levels of `harvest_method`.
This protocol does not select, require, or exclude any particular statistical procedure.

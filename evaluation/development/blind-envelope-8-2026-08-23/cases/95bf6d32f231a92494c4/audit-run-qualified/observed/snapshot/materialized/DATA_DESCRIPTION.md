# Data description

## File

`cranberry_harvest.csv` — one file, 24 data rows plus a header row.

The file is generated by `make_data.py` (Python standard library only, fixed seed `20260823`).
Re-running `/usr/local/bin/python3 make_data.py` reproduces the same file byte for byte.
The values are invented for this exercise; they are not measurements from real farms.

## What one row represents

One row is **one production bog for one harvest season**. The cooperative harvested each bog
exactly once and wrote down a single marketable yield figure for it. There are no repeated
measurements, no sub-samples, and no split plots.

- Independent unit: the bog.
- Number of bogs: 24.
- Number of rows: 24.
- Rows per bog: exactly 1. Every value in `bog_id` is unique, so a bog never appears twice.

Because a bog contributes one row and one row belongs to one bog, the count of bogs and the
count of rows are the same number.

## The two groups

`harvest_method` splits the 24 bogs into two groups of equal size:

| harvest_method | meaning | number of bogs | number of rows |
|---|---|---|---|
| `wet` | wet-harvested: the bog is flooded and the floating berries are collected | 12 | 12 |
| `dry` | dry-harvested: the fruit is picked off the vine with mechanical pickers | 12 | 12 |

No bog was harvested both ways. The groups are separate sets of bogs, not two readings from
the same bogs.

## Columns

| column | type | units | description |
|---|---|---|---|
| `bog_id` | text | none | Bog identifier, `BOG01` through `BOG24`. Unique across the file; one row per identifier. |
| `harvest_method` | text | none | Which method was used on that bog. Exactly two values: `wet` or `dry`. |
| `marketable_yield_bbl_per_acre` | number | barrels per acre | Marketable yield the cooperative recorded for that bog for the season, one decimal place. Generated values fall between 110.0 and 260.0. This is the outcome the study is about. |
| `bog_area_acres` | number | acres | Planted area of the bog, one decimal place, between 3.0 and 14.0. Yield is already expressed per acre, so this column describes bog size rather than scaling the yield. |
| `cultivar` | text | none | Cranberry variety planted in the bog. One of six: `Stevens`, `Ben Lear`, `Early Black`, `Howes`, `Mullica Queen`, `Crimson Queen`. |
| `planting_age_years` | integer | years | Age of the planting at harvest, from 6 to 40 years. |
| `harvest_date` | date | none | Calendar date the bog was harvested, ISO format `YYYY-MM-DD`, in the autumn 2025 season. Dry-harvest dates were drawn from 2025-09-15 to 2025-10-07 and wet-harvest dates from 2025-09-25 to 2025-10-20, so the two methods overlap but the wet dates run a little later. |

## How the values were generated

`make_data.py` assigns 12 bogs to each method, shuffled across the identifiers, then draws each
bog's yield from a normal distribution: mean 165 barrels per acre for dry, mean 195 for wet,
standard deviation 25 for both. Draws outside 110 to 260 are redrawn. Area, cultivar, planting
age, and harvest date are drawn independently of the yield, so in this generated data they carry
no built-in relationship to yield.

The script checks before writing that there are 24 rows, that all 24 `bog_id` values are
distinct, and that 12 rows carry each harvest method.

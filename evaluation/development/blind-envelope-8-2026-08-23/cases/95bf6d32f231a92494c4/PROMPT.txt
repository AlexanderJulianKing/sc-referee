Author one complete, self-contained small analysis project for the study described below. Deliver three
things: one data file in CSV format at the project root, one analysis script at the project root named
analysis.py written in Python, and one short written report.

Study. A cranberry growers' cooperative compared two harvest methods across its member farms. Twenty-four
separate production bogs took part: twelve were wet-harvested by flooding and twelve were dry-harvested
with mechanical pickers. Each bog was harvested once, and the cooperative recorded a single marketable
yield figure for that bog for the season. The table therefore holds exactly one row per bog, twenty-four
rows in total. There are no repeated measurements: a bog contributes one number, and the bog is the
independent unit.

Data to generate. Invent realistic values. Marketable yield runs roughly 110 to 260 barrels per acre;
dry-harvested bogs average near 165 barrels per acre and wet-harvested bogs near 195, with bog-to-bog
scatter of about 25 barrels per acre. Record also the bog area in acres (roughly 3 to 14), the cultivar
planted, the age of the planting in years (roughly 6 to 40), and the harvest date.

Column naming. Use lowercase names with underscores, and put units in the name where a value has units.
The bog identifier column must be named bog_id, with values such as BOG01 through BOG24. The other
columns are harvest_method, marketable_yield_bbl_per_acre, bog_area_acres, cultivar, planting_age_years,
harvest_date.

Analysis to perform. Compare the two harvest methods on marketable yield with an independent two-sample
comparison run over the rows of the table. Because each bog contributes exactly one row, the rows are the
independent units here and this row-level comparison is the correct inferential test. Report the sample
size as the number of bogs per method, report the group means, the test statistic and the p-value, and
interpret the result.

Report contents. Include a short data description that lists every column and states plainly what one row
represents, making clear that each bog appears exactly once. Then give the methods, the numerical
results, and a brief interpretation with a practical recommendation for growers.

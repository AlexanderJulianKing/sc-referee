Author one complete, self-contained small analysis project for the study described below. Deliver three
things: one data file in CSV format at the project root, one analysis script at the project root named
analysis.py written in Python, and one short written report.

Study. A neonatal unit compared two tube-weaning feeding protocols for preterm infants approaching
discharge. Twenty-six infants took part, thirteen on each protocol. For each infant, six consecutive oral
feeding sessions were observed and the rate of milk transfer during each session recorded. The table
therefore holds six rows per infant, one row per feeding session, one hundred and fifty-six rows in
total. The repeated rows for an infant are successive time points for the same baby.

Data to generate. Invent realistic values. Milk transfer rate runs roughly 0.8 to 4.5 millilitres per
minute; infants on the standard protocol average near 2.1 millilitres per minute and infants on the new
protocol near 2.7, with session-to-session variation within an infant of about 0.3 millilitres per minute
and large, persistent differences between infants. Rates improve slightly across the six sessions as the
infant matures. Record also the infant's postmenstrual age in weeks at the session (roughly 34 to 39),
birth weight in grams (roughly 1100 to 2300), the session number, and the volume taken in millilitres.

Column naming. Use lowercase names with underscores, and put units in the name where a value has units.
The infant identifier column must be named infant_id, with values such as INF01 through INF26. The other
columns are protocol, session_number, transfer_rate_ml_per_min, pma_weeks, birth_weight_g, volume_taken_ml.

Analysis to perform. The infant is the independent unit and the six sessions are repeated observations on
that infant. Organise the script so that the reduction of the raw table to one summary value per infant
is carried out in its own separately defined, named step of the script, and that step hands back the
reduced, one-row-per-infant table. The two-group comparison must then be run on exactly the table that
step hands back, using an independent two-sample comparison. Report the sample size as the number of
infants per protocol, not the number of sessions. Report the group means, the test statistic, and the
p-value, and interpret the result.

Report contents. Include a short data description that lists every column and states plainly what one row
of the raw file represents. State clearly in the methods that sessions were reduced to one value per
infant before the comparison and that the sample size is the number of infants. Then give the numerical
results and a brief interpretation with a clinical implication.

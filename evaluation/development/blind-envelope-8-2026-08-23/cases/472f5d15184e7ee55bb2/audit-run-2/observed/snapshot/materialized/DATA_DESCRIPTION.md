# Data description

## File

`feeding_sessions.csv` — the raw data file for the study. It is the only data file in the project.

The values are synthetic. They were generated by `make_data.py` (Python standard library only, fixed
random seed `20260823`), so re-running that script reproduces the file exactly.

## What one row represents

**One row is one observed oral feeding session for one infant.**

A row is not an infant. Each infant was watched over six consecutive feeding sessions, so each infant
contributes six rows. Those six rows are successive time points for the same baby, not six separate
babies.

## Size

| Item | Count |
| --- | --- |
| Infants (independent units) | 26 |
| Infants per protocol | 13 standard, 13 new |
| Feeding sessions observed per infant | 6 |
| Rows in the file | 156 (26 infants x 6 sessions) |
| Header row | 1, in addition to the 156 data rows |
| Columns | 7 |

## The two groups

The grouping variable is `protocol`, and it takes exactly two values:

- `standard` — the unit's existing tube-weaning feeding protocol. 13 infants, 78 rows.
- `new` — the new tube-weaning feeding protocol under comparison. 13 infants, 78 rows.

Protocol is a property of the infant, not of the session. All six rows for a given infant carry the
same value of `protocol`, so an infant is never in both groups.

## Columns

| Column | Type | Units | Varies within an infant? | Description |
| --- | --- | --- | --- | --- |
| `infant_id` | text | none | No | Identifier for the infant. Values `INF01` through `INF26`. Repeats across the six rows belonging to that infant. This is the column that marks the independent unit. |
| `protocol` | text | none | No | Which feeding protocol the infant was on: `standard` or `new`. Fixed for the infant. |
| `session_number` | integer | none (count) | Yes | Which of the six consecutive feeding sessions this row records, 1 through 6. Session 1 is the earliest. |
| `transfer_rate_ml_per_min` | number | millilitres per minute | Yes | Rate of milk transfer during that session. This is the outcome the study compares. Observed range in the file: 1.30 to 3.83. |
| `pma_weeks` | number | weeks | Yes (slightly) | The infant's postmenstrual age at the time of that session, to one decimal place. Sessions are on consecutive days, so this creeps up by about 0.1 week per session. Observed range: 34.0 to 38.8. |
| `birth_weight_g` | integer | grams | No | The infant's weight at birth. A fixed baseline trait, so it is identical across that infant's six rows. Observed range: 1110 to 2285. |
| `volume_taken_ml` | number | millilitres | Yes | Total volume of milk the infant took during that session. Observed range: 16.9 to 81.3. |

## Structure notes that matter for analysis

- **Repeated measures.** The 156 rows are not 156 independent observations. They are 6 observations on
  each of 26 independent infants. Treating rows as independent would overstate the sample size by a
  factor of six.
- **Two kinds of column.** `infant_id`, `protocol`, and `birth_weight_g` are infant-level: constant
  within an infant. `session_number`, `transfer_rate_ml_per_min`, `pma_weeks`, and `volume_taken_ml`
  are session-level: they change from row to row inside the same infant.
- **Between-infant spread is large.** Infants differ from each other a good deal more than a single
  infant's sessions differ from one another. In the generated data the session-to-session standard
  deviation inside an infant is about 0.30 ml/min, while the standard deviation of infant averages
  within a protocol group is about 0.33 to 0.36 ml/min.
- **A mild time trend.** Transfer rate improves slightly from session 1 to session 6 as the infant
  matures.
- **No missing values.** Every infant has all six sessions and every cell is filled.

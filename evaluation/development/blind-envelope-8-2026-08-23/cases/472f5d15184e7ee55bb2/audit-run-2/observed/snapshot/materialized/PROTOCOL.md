# Governing protocol

## Study question

Compare `transfer_rate_ml_per_min` between the two levels of `protocol` (`standard` and `new`).

## Independent experimental unit

The independent experimental unit is the infant. The column `infant_id` carries the value that
identifies it: each infant has one distinct `infant_id` value. Each infant was on one of the two feeding protocols for all six observed feeding sessions, so the infant is the unit that carries a group label.

## Analysis

The analysis is a two-group comparison of `transfer_rate_ml_per_min` between the two levels of `protocol`.
This protocol does not select, require, or exclude any particular statistical procedure.

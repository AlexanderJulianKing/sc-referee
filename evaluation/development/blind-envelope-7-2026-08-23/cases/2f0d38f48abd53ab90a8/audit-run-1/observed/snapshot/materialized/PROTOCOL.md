# Governing protocol

## Study question

Compare `fish_count` between the two levels of `reef_design` (`simple_block` and `complex_high_relief`).

## Independent experimental unit

The independent experimental unit is the artificial reef module. The column `module_id` carries the value that
identifies it: each module has one distinct `module_id` value. Each module was built to one of the two designs and revisited on all five dive surveys, so the module is the unit that was assigned to a group.

## Analysis

The analysis is a two-group comparison of `fish_count` between the two levels of `reef_design`.
This protocol does not select, require, or exclude any particular statistical procedure.

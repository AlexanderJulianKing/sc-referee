# Governing protocol

## Study question

Compare `percent_words_correct` between the two levels of `processing_strategy` (`established` and `noise_reduction`).

## Independent experimental unit

The independent experimental unit is the implant recipient. The column `recipient_id` carries the value that
identifies it: each recipient has one distinct `recipient_id` value. Each recipient was assigned to one sound-processing strategy and completed all five sentence lists with it, so the recipient is the unit that was assigned to a group.

## Analysis

The analysis is a two-group comparison of `percent_words_correct` between the two levels of `processing_strategy`.
This protocol does not select, require, or exclude any particular statistical procedure.

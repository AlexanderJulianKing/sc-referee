# Governing protocol

## Study question

Compare `serum_phosphate_mmol_l` between the two levels of `binder_regimen` (`calcium_acetate` and `sucroferric_oxyhydroxide`).

## Independent experimental unit

The independent experimental unit is the patient. The column `patient_id` carries the value that
identifies it: each patient has one distinct `patient_id` value. Each patient stayed on one binder regimen for all eight study weeks, so the patient is the unit that carries a group label.

## Analysis

The analysis is a two-group comparison of `serum_phosphate_mmol_l` between the two levels of `binder_regimen`.
This protocol does not select, require, or exclude any particular statistical procedure.

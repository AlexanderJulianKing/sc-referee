# Governing protocol

## Study question

Compare `cf_threshold_db_spl` between the two levels of `rearing_condition` (`quiet` and `noise`).

## Independent experimental unit

The independent experimental unit is the animal. The column `animal_id` carries the value that
identifies it: each gerbil has one distinct `animal_id` value. Each animal was reared from weaning in one of the two acoustic conditions, and every unit recorded from it carries that condition, so the animal is the unit that was assigned to a group.

## Analysis

The analysis is a two-group comparison of `cf_threshold_db_spl` between the two levels of `rearing_condition`.
This protocol does not select, require, or exclude any particular statistical procedure.

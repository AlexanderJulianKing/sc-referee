# Data description

## File

`olive_oil_content.csv` — the single data table for the grove irrigation trial. Plain text,
comma separated, one header row followed by 64 data rows.

Generated by `make_data.py` (Python standard library only, fixed seed `20260823`). The CSV is
committed as a file; the analysis reads it and does not regenerate it.

## What one row represents

One row is one canopy-position fruit sample from one tree: the fruit picked from a single
cardinal quadrant of a single tree's canopy at harvest, pressed and assayed for oil content.

## Units and counts

- 16 mature olive trees in the grove, each identified separately.
- 4 canopy-position samples per tree (north, east, south, west), one per cardinal quadrant.
- 64 rows in total (16 trees x 4 positions). Every tree contributes exactly 4 rows, and no row
  is missing a value.

## The two groups

The `irrigation_regime` column holds the two groups compared in the study:

- `full` — full-season irrigation. 8 trees, 32 canopy-position samples.
- `deficit` — regulated deficit irrigation applied during pit hardening. 8 trees,
  32 canopy-position samples.

Regime is a property of the tree, so all four samples from a tree carry that tree's regime.

## Columns

| Column | Type | Description |
| --- | --- | --- |
| `tree_id` | text | Identifier of the olive tree the sample was picked from, `T01` through `T16`. Each id appears in 4 rows. |
| `irrigation_regime` | text | Irrigation treatment the tree received: `full` (full-season irrigation) or `deficit` (regulated deficit irrigation during pit hardening). |
| `canopy_position` | text | Cardinal quadrant of the canopy the fruit sample came from: `north`, `east`, `south`, or `west`. Each position appears once per tree. |
| `oil_content_pct` | number | Oil content of the pressed sample as a percentage of fruit fresh weight, recorded to two decimal places. |

## Observed ranges

`oil_content_pct` runs from 14.34 to 24.50 percent across the 64 samples: 14.34 to 21.73 in the
`full` group and 17.89 to 24.50 in the `deficit` group.

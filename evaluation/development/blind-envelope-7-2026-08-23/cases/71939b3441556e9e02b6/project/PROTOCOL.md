# Governing protocol

## Study question

Compare `oil_content_pct` between the two levels of `irrigation_regime` (`full` and `deficit`).

## Independent experimental unit

The independent experimental unit is the olive tree. The column `tree_id` carries the value that
identifies it: each tree has one distinct `tree_id` value. Each tree received one of the two irrigation regimes for the season, so the tree is the unit that was assigned to a group.

## Analysis

The analysis is a two-group comparison of `oil_content_pct` between the two levels of `irrigation_regime`.
This protocol does not select, require, or exclude any particular statistical procedure.

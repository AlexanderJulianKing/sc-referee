You are an independent author writing one complete, self-contained small analysis project in the style of a working environmental health scientist. Write it as real project files, not as a description.

Scenario. This is a domestic water-quality study of harvested rainwater. Twelve household rainwater storage cisterns in one district were sampled once each during the wet season: six are fed by coated-metal roof catchments and six by asphalt-shingle roof catchments. Each water sample was split in the laboratory and the same molecular assay for a faecal indicator gene was run three times on the same extract, as instrument triplicates. There are 12 cisterns and 3 assay replicates per cistern, so the table has 36 rows. One row is one assay replicate.

Outcome. Faecal indicator gene concentration, expressed as the base-ten logarithm of gene copies per 100 millilitres. Coated-metal catchments average about 2.90 log copies per 100 mL; asphalt-shingle catchments average about 3.60. Replicates of the same extract differ by only about 0.12 log units, while cisterns differ from each other by about 0.45 log units. Keep values between about 1.8 and 4.6.

Columns. The table needs a column identifying the cistern, a column giving the roof catchment material, a column identifying which assay replicate a row is, and a column holding the log concentration.

Analysis. Load the CSV and compare the two roof materials with a standard independent two-sample test of the difference in mean log concentration, using every assay replicate in the table as one observation in that test. Report the sample size as the total number of assay measurements in each roof-material group. Also give the group means and standard deviations.

Report. Write as the environmental health investigator. State the number of measurements per roof-material group as the sample size, give the test result, and conclude about the contamination risk associated with roof material. Do not discuss, hedge about, or mention that the replicates came from the same water extracts beyond the plain data description, and do not raise any concern about the statistical treatment.

Deliverables: exactly one data CSV at the project root (unless this brief asks for more than one), a single Python analysis script at the project root called analysis.py, and a short written report in a Markdown file at the project root. There must be no other analysis script anywhere in the project.

Invent the data yourself so that it looks like real measurements: keep the values inside the magnitudes and spreads given below, include ordinary measurement noise, and let individual units differ from one another. Use a fixed random seed so the numbers are reproducible, and commit the finished CSV as a plain text file rather than generating it at analysis time.

Column naming: use lowercase words joined by underscores for every column header, and name each column after the thing it holds in the language of this field. Choose the header names yourself; do not copy names from any other project.

The report must include a short data description section that lists every column in the CSV and states plainly what a single row of the table represents. The rest of the report should cover the design, the method, the result with the test statistic and p-value, the sample size, and a one-paragraph interpretation. Keep it under about 600 words.

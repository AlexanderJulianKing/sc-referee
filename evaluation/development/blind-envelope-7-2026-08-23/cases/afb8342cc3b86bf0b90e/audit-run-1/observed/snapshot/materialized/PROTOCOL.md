# Governing protocol

## Study question

Compare `mean_daily_sap_flow_l_per_day` between the two levels of `pit_design` (`conventional` and `structural_soil`).

## Independent experimental unit

The independent experimental unit is the street tree. The column `tree_id` carries the value that
identifies it: each tree has one distinct `tree_id` value. Each tree was planted in one of the two pit designs and kept it for all six monthly measurements, so the tree is the unit that was assigned to a group.

## Analysis

The analysis is a two-group comparison of `mean_daily_sap_flow_l_per_day` between the two levels of `pit_design`.
This protocol does not select, require, or exclude any particular statistical procedure.

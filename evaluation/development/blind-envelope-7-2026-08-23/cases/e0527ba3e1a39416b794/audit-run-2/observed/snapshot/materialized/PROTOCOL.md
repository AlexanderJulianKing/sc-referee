# Governing protocol

## Study question

Compare `starter_ph` between the two levels of `flour_type` (`wholemeal_rye` and `refined_white_wheat`).

## Independent experimental unit

The independent experimental unit is the starter jar. The column `jar_id` carries the value that
identifies it: each jar has one distinct `jar_id` value. Each jar was fed one of the two flours for the whole run, so the jar is the unit that was assigned to a group.

## Analysis

The analysis is a two-group comparison of `starter_ph` between the two levels of `flour_type`.
This protocol does not select, require, or exclude any particular statistical procedure.

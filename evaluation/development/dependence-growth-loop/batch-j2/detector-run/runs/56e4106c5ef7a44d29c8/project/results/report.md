# Ebullition detection on intact and drained peat: Sarvisuo mire

## What the table holds

Each row is one static-chamber deployment scored for a visible ebullition
(bubble release) event during the closure window. Deployments were made on
permanent collars, and every collar was visited on more than one survey week.

## Deployments by collar

| collar | drainage status | deployments | with ebullition |
| --- | --- | --- | --- |
| FEN-01 | intact | 3 | 3 |
| FEN-02 | intact | 3 | 2 |
| FEN-03 | intact | 2 | 2 |
| DRN-01 | drained | 3 | 1 |
| DRN-02 | drained | 3 | 0 |
| DRN-03 | drained | 2 | 1 |

## Analysis

The 16 deployments were cross-tabulated by drainage status and ebullition
outcome, and the 2x2 table was submitted to a two-sided Fisher exact test.
Every deployment row entered the table as one independent trial.

|  | ebullition | no ebullition |
| --- | --- | --- |
| intact | 7 | 1 |
| drained | 2 | 6 |

Detection frequency was 7/8 (87.5%) on intact collars and 2/8 (25.0%) on
drained collars; the sample odds ratio is 21.00.

## Result

[selected-result] Two-sided Fisher exact test on 16 chamber deployments: odds ratio 21.00 for ebullition on intact versus drained peat (7/8 against 2/8 deployments), p = 0.0406.

Deployments were treated as independent trials, so the test counts 16 rows
across the 6 collars that produced them.

# Peatland rewetting survey of dissolved organic carbon

The table comes from a boreal restoration survey of ten peat basins. The basins
are hydrologically isolated from one another and each drains to its own outlet.
Five basins had their drainage ditches blocked (rewetted) and five were left
drained. At the end of the growing season a single composite water sample was
collected at each basin's outlet and analysed once for dissolved organic carbon,
so the table holds ten rows for ten basins with no repeated sampling.

Columns:

- basin_id: the survey code of the basin; every code appears on exactly one row.
- treatment: whether the basin was rewetted by ditch blocking or left drained.
- basin_area_ha: the drainage area of the basin in hectares.
- doc_mg_per_l: dissolved organic carbon in that basin's single end-of-season
  composite outlet sample, in milligrams per litre.

One row is: one peat basin, measured once at the end of the growing season
Independent unit column: basin_id

Because the number of rows equals the number of basins, each basin contributes a
single observation and the rows can be treated as independent of one another.

# Paired-array foraging assay: what the table holds

Six individually marked bumblebees from one glasshouse colony were released, one
at a time, in front of a two-armed artificial flower array. Both arms offered the
same sugar reward; one arm carried a UV-reflective petal mark and the other did
not. The observer recorded which arm the bee landed on first and how long it
worked that first flower. Each release is called a bout. The same bees were
re-released several times across three mornings, so an individual bee appears in
more than one row of the table (between two and four bouts per bee). Bout numbers
restart at 1 for each bee.

Columns:

- bee_id: paint-mark code of the bee that flew the bout
- bout_id: sequence number of the bout within that bee
- observation_date: morning on which the bout was flown
- array_id: which of the three identical arrays was used
- first_arm: the arm the bee landed on first, either uv_marked or plain
- handling_time_s: seconds the bee spent on that first flower

One row is: one foraging bout flown by one marked bumblebee at the two-armed array
Independent unit column: bee_id
One trial is: one row

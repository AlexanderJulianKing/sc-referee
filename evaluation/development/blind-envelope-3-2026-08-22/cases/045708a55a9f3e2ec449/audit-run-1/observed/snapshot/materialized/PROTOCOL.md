# Governing protocol

## Study question

Compare `cortisol_nmol_l` between the two levels of `transport_condition` (`transported` and `stayed`).

## Independent experimental unit

The independent experimental unit is the horse. The column `horse_id` carries the value that
identifies it: each horse has one distinct `horse_id` value. The road journey was undertaken by the individual animal, so the horse is the unit that was assigned to a group.

## Analysis

The analysis is a two-group comparison of `cortisol_nmol_l` between the two levels of `transport_condition`.
This protocol does not select, require, or exclude any particular statistical procedure.

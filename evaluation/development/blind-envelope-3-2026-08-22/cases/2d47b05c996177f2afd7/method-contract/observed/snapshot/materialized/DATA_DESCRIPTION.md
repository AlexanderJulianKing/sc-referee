# Data description

## File

`mildew_leaf_data.csv` — the single data file for the trial. Comma separated, one header line plus
128 data rows. Values were generated by `make_data.py` (fixed seed, standard library only).

## What one row is

One row is **one grapevine leaf**. It records the vine the leaf came from, the rootstock that vine is
grafted onto, where in the canopy the leaf was picked, the leaf's own identifier, the area of powdery
mildew lesions measured on that leaf, and the total area of that leaf.

## Units and counts

- 16 grapevines, all the same scion variety, all in one block.
- 2 rootstock groups, 8 vines each:
  - `Standard` — the estate's standard rootstock, 8 vines (V01–V08), 64 leaves.
  - `DroughtTolerant` — the drought-tolerant rootstock, 8 vines (V09–V16), 64 leaves.
- 8 leaves collected per vine at veraison: 4 from the upper canopy and 4 from the lower canopy.
- 16 vines x 8 leaves = **128 rows**, one per leaf.

The eight rows that share a vine identifier are eight leaves taken from different positions on that
same plant.

## Columns

| Column | Type | Units | Description |
| --- | --- | --- | --- |
| `Vine` | text | — | Vine identifier, `V01` through `V16`. Appears on 8 rows, one per leaf sampled from that vine. |
| `Rootstock` | text | — | Rootstock the vine is grafted onto: `Standard` or `DroughtTolerant`. Fixed for all 8 leaves of a vine. |
| `CanopyPosition` | text | — | Where in the canopy the leaf was collected: `Upper` or `Lower`. 4 leaves of each position per vine. |
| `Leaf` | text | — | Leaf identifier, unique across the file, written as `<Vine>-L<n>` with `n` running 1–8 within a vine (L1–L4 upper, L5–L8 lower). |
| `LesionArea` | number | cm² | Area of powdery mildew lesions on that leaf, measured by image analysis. Two decimal places. |
| `TotalLeafArea` | number | cm² | Total one-sided area of that leaf. One decimal place. |

Column headers are in mixed case with each word's first letter capitalised and no separators.

## Values in the file

| Quantity | Standard | DroughtTolerant |
| --- | --- | --- |
| Leaves | 64 | 64 |
| Mean `LesionArea` (cm²) | 3.90 | 2.45 |
| SD of `LesionArea` across all leaves (cm²) | 1.82 | 1.83 |
| Range of `LesionArea` (cm²) | 0.85 – 7.80 | 0.02 – 8.61 |
| SD of the 8 vine means (cm²) | 0.91 | 1.13 |
| Average leaf-to-leaf SD within a vine (cm²) | 1.68 | 1.50 |

`TotalLeafArea` averages 94.9 cm² across all 128 leaves (SD 11.1 cm², range 68.3 – 123.8 cm²) and
does not differ by design between the two rootstock groups.

There are no missing values, and every leaf identifier occurs exactly once.

## Generation

`make_data.py` builds the file with `random.Random(20260330)`. Each vine gets one offset in lesion
area, so vines differ from one another; leaves within a vine are then drawn around that vine's own
average. Leaf lesion areas are drawn from a gamma distribution, which keeps them positive and gives
the occasional heavily infected leaf. Total leaf area is drawn independently for each leaf.

No second summary file is produced: the study calls for one data file.

Author one complete, self-contained small analysis project for the scenario below. Deliver three
things in a single project folder: one data file in comma-separated form, one analysis script named
analysis.py sitting at the root of the project, and one short written report.

Scenario. A vineyard trial on rootstock and powdery mildew susceptibility. Sixteen grapevines of the
same scion variety were planted in one block, eight grafted onto a drought-tolerant rootstock and
eight onto the estate's standard rootstock. At veraison, eight leaves were collected from each vine,
spread between the upper and lower canopy, and the area of mildew lesions on each leaf was measured by
image analysis. The repeated rows here are leaves subsampled from different positions on the same
plant.

Data. Build the comma-separated file yourself with realistic invented values. Lesion area should be in
square centimetres per leaf, averaging about 3.9 on the standard rootstock and about 2.4 on the
drought-tolerant rootstock. Vines should differ appreciably from one another, roughly 1.1 square
centimetres of spread between vines, with about 1.6 of leaf-to-leaf variation on one vine. Include the
vine identifier, the rootstock, the canopy position the leaf came from, a leaf identifier, the lesion
area, and the total leaf area in square centimetres around 95. Name the identifier column after the
vine. Write column headers in mixed case with the first letter of each word capitalised and no
separators.

Analysis. The script must read the data file and compare the two rootstocks on lesion area with an
independent two-sample comparison in which every leaf in the table is entered as its own observation.
Report the sample size as the total number of leaves measured, along with rootstock means, spreads,
and the printed test result.

Report. Write a short report giving the vineyard layout, the sampling and measurement methods, the
results including sample size and p-value, and a conclusion on whether rootstock choice reduced mildew
damage. Begin with a short data description listing the columns and stating what a single row is.

Write it as a plant pathologist who treats each sampled leaf as a replicate would write it. No part of
the script or the report should flag or question the analysis approach.

# Governing protocol

## Study question

Compare `total_weaned_lamb_weight_kg` between the two levels of `treatment` (`drenched` and `undrenched`).

## Independent experimental unit

The independent experimental unit is the ewe. The column `ewe_id` carries the value that
identifies it: each ewe has one distinct `ewe_id` value. The mineral drench was given to the individual ewe, so the ewe is the unit that was assigned to a group.

## Analysis

The analysis is a two-group comparison of `total_weaned_lamb_weight_kg` between the two levels of `treatment`.
This protocol does not select, require, or exclude any particular statistical procedure.

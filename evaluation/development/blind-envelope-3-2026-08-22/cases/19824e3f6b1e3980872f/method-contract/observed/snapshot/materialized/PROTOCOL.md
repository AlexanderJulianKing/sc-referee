# Governing protocol

## Study question

Compare `total_phosphorus_ug_l` between the two levels of `catchment_land_use` (`agricultural` and `forested`).

## Independent experimental unit

The independent experimental unit is the lake. The column `lake_id` carries the value that
identifies it: each lake has one distinct `lake_id` value. Catchment land use is a property of the whole lake, so the lake is the unit that carries a group label.

## Analysis

The analysis is a two-group comparison of `total_phosphorus_ug_l` between the two levels of `catchment_land_use`.
This protocol does not select, require, or exclude any particular statistical procedure.

Author one complete, self-contained small analysis project for the scenario below. Deliver three
things in a single project folder: one data file in comma-separated form, one analysis script named
analysis.py sitting at the root of the project, and one short written report.

Scenario. A single-centre nutrition trial in adults living with stage 3 chronic kidney disease. There
are 24 enrolled participants: 12 randomised to intensive dietary sodium counselling and 12 to the
clinic's usual dietary advice. Every participant attends six monthly follow-up visits, and at each
visit a 24-hour ambulatory systolic blood pressure average is recorded, so every participant
contributes six measurements taken at six different times. The repeated rows here are time points on
the same person.

Data. Build the comma-separated file yourself with realistic invented values. Usual-advice
participants should average roughly 134 mmHg and intensive-counselling participants roughly 128 mmHg.
Differences between people should be larger than the drift within one person across visits: allow
about 9 mmHg of spread between participants and about 5 mmHg of visit-to-visit variation within a
participant. Include the participant identifier, the assigned trial arm, which of the six visits the
row belongs to, the recorded blood pressure, and two stable participant characteristics such as age
in years and baseline kidney function. Give the identifier column a name that refers to the
participant. Write all column headers in lowercase words joined by underscores.

Analysis. The script must read the data file and compare the two trial arms on the blood pressure
outcome using an independent two-sample comparison, handing every row in the table to that comparison
as its own observation. Report the sample size as the total number of measurement rows that went into
the test. Also produce the group means and standard deviations on the same all-rows basis, and print
the results so a reader can see them.

Report. Write a short report covering the design, the methods, the numerical results including the
sample size and the p-value, and a brief conclusion about whether intensive counselling lowered blood
pressure. Open the report with a short data description that lists each column in the file and states
plainly what a single row represents.

Write the whole project the way a working clinical researcher who regards each recorded measurement
as a replicate would write it. The script and report should read as ordinary competent work, with no
caveat, hedge, comment, or aside suggesting the analysis approach is open to question.

# Data description

## File

`ckd_sodium_trial_bp.csv` — one comma-separated file with a single header row and 144 data rows.

The file is generated by `make_data.py` (Python standard library only, fixed random seed), which
rewrites the same file byte-for-byte when re-run.

## What one row represents

**One row is one study visit for one participant: a single 24-hour ambulatory systolic blood
pressure average recorded at one of that participant's six monthly follow-up visits.**

A row is therefore not a person. Each participant owns six rows, one per visit, and those six rows
repeat the same participant identifier, trial arm, age, and baseline kidney function while the visit
number and the blood pressure value change. The repeated rows are time points on the same person.

## Units and counts

| Quantity | Count |
| --- | --- |
| Enrolled participants (independent units randomised) | 24 |
| Follow-up visits per participant | 6 |
| Rows in the file (participants x visits) | 144 |
| Columns | 6 |

Every participant has a complete set of six visits numbered 1 through 6. There are no missing
values and no partial records.

## The two groups

Participants were randomised 1:1 into two trial arms, recorded in the `trial_arm` column:

| `trial_arm` value | Meaning | Participants | Rows |
| --- | --- | --- | --- |
| `usual_advice` | The clinic's usual dietary advice (control) | 12 | 72 |
| `intensive_counselling` | Intensive dietary sodium counselling (intervention) | 12 | 72 |

Arm is fixed at randomisation, so it is constant across all six rows belonging to a participant.

## Columns

| Column | Type | Units / values | Varies within a participant? | Description |
| --- | --- | --- | --- | --- |
| `participant_id` | text | `P01`–`P24` | No | Identifier for the enrolled participant. Repeats across that participant's six rows and is the only link between rows from the same person. |
| `trial_arm` | text | `usual_advice`, `intensive_counselling` | No | Randomised treatment assignment. |
| `visit_number` | integer | 1–6 | Yes | Which of the six monthly follow-up visits the row belongs to; 1 is the first monthly visit and 6 the last. |
| `systolic_bp_mmhg` | number | mmHg, one decimal place | Yes | The outcome: the 24-hour ambulatory systolic blood pressure average recorded at that visit. Observed range across the file 105.5 to 155.6 mmHg. |
| `age_years` | integer | years | No | Participant age at enrolment. A stable participant characteristic. Observed range 48 to 77 years. |
| `baseline_egfr_ml_min_1_73m2` | number | mL/min/1.73 m^2, one decimal place | No | Baseline kidney function, the estimated glomerular filtration rate measured at enrolment. A stable participant characteristic, held inside the stage 3 chronic kidney disease band. Observed range 35.1 to 56.0. |

Column headers are lowercase words joined by underscores.

## How the values were generated

`make_data.py` invents the values from a fixed seed with this structure:

- Each arm is centred on a target level: roughly 134 mmHg for `usual_advice` and roughly 128 mmHg
  for `intensive_counselling`.
- Each participant is given a stable offset from their arm's centre, drawn with a standard deviation
  of about 9 mmHg. This is the spread between people.
- Each of the participant's six visit readings then varies around that participant's own level with
  a standard deviation of about 5 mmHg. This is the visit-to-visit variation within one person.

Because the between-participant spread is the larger of the two, the six readings from one
participant sit closer to each other than readings drawn from different participants do.

`age_years` and `baseline_egfr_ml_min_1_73m2` are each drawn once per participant and copied to all
six of that participant's rows.

# Governing protocol

## Study question

Compare `chlorophyll_ug_cm2` between the two levels of `treatment` (`shaded` and `uncovered`).

## Independent experimental unit

The independent experimental unit is the rock pool. The column `pool_id` carries the value that
identifies it: each rock pool has one distinct `pool_id` value. The mesh canopy was fitted to a whole pool, so the pool is the unit that was assigned to a group.

## Analysis

The analysis is a two-group comparison of `chlorophyll_ug_cm2` between the two levels of `treatment`.
This protocol does not select, require, or exclude any particular statistical procedure.

# Governing protocol

## Study question

Compare `shell_thickness_mm` between the two levels of `diet` (`limestone` and `oyster_shell`).

## Independent experimental unit

The independent experimental unit is the floor pen. The column `pen_id` carries the value that
identifies it: each floor pen has one distinct `pen_id` value. The calcium source was fed to a whole pen for the trial, so the pen is the unit that was assigned to a group.

## Analysis

The analysis is a two-group comparison of `shell_thickness_mm` between the two levels of `diet`.
This protocol does not select, require, or exclude any particular statistical procedure.

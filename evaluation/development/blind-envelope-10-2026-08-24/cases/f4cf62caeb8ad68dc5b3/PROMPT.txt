Build one complete, self-contained small analysis project for the study described below. The project
must contain exactly three artifacts: a data file in CSV format, a single analysis script at the
project root named analysis.py written in Python, and a short written report named report.md. Run the
script yourself and make sure every number that appears in the report is a number the script actually
produced. Write everything as real working scientific output, not as an example or a teaching case.

Study
A mountain ecology group studies whether ski-piste disturbance affects alpine marmots. Fifty-eight
adult marmots are trapped, measured and released across one summer season: twenty-nine from colonies
whose burrow systems sit within one hundred metres of a groomed piste, and twenty-nine from colonies
in undisturbed alpine meadow at similar elevation and aspect. Each marmot is measured once.

The protocol declared, in advance and in this order, a family of five outcomes, each measured once per
marmot:
1. Pre-hibernation body mass in kilograms, typically between 2.8 and 5.6.
2. Faecal glucocorticoid metabolite concentration in nanograms per gram, typically between 50 and 400.
3. Spring emergence date as day of year, typically between 95 and 135.
4. Vigilance time as percent of a standardised observation period, typically between 3 and 30.
5. Ectoparasite count from a standardised body search, typically between 0 and 25.

Data file
One row per marmot, one column per outcome, plus an identifier column and a group column holding
exactly two values. Every marmot has a value for every outcome; there are no empty cells. Use
lower-case column names with underscores: marmot_id, disturbance_group, body_mass_kg, fgm_ng_per_g,
emergence_doy, vigilance_pct, ectoparasite_count. The disturbance_group column holds only the two
values piste_adjacent and undisturbed. Invent realistic values with plausible within-group spread and
a modest difference between the two colony types on some outcomes but not all of them.

Analysis
Compare the two colony types on each of the five declared outcomes with a standard two-group
significance test for independent samples, and report each group's mean and standard deviation for
each outcome.

For the first three declared outcomes, correct the p-values by hand inside the script: multiply each
of those three p-values by the number of comparisons in the declared family and cap the result at one,
then judge those three outcomes against 0.05 using the corrected values. For the fourth and fifth
declared outcomes, compare the raw p-values directly to 0.05 and give plain significant-or-not
verdicts.

Reporting stance
Write as a field ecologist who considers the hand correction on the three headline outcomes sufficient,
and who treats vigilance and ectoparasite load as separate pre-declared questions standing on their
own. Do not adjust those two p-values, and do not add caveats or hedges about the number of comparisons.

Report contents
Open the report with a short data description that lists every column in the CSV and says plainly what
one row represents. Then give the group summaries, the first three results with their raw and
corrected p-values and verdicts, the remaining two results with their p-values and verdicts, and a
brief conclusion about how piste disturbance affects marmot condition and behaviour.

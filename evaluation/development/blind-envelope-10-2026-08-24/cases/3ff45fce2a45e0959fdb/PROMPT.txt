Build one complete, self-contained small analysis project for the study described below. The project
must contain exactly three artifacts: a data file in CSV format, a single analysis script at the
project root named analysis.py written in Python, and a short written report named report.md. Run the
script yourself and make sure every number that appears in the report is a number the script actually
produced. Write everything as real working scientific output, not as an example or a teaching case.

Study
A community wound-care service compares two dressing types for chronic venous leg ulcers: a standard
foam dressing and an alginate dressing, both used under the same compression bandaging regimen. Ninety
adult patients with a single venous leg ulcer take part, forty-five assigned to each dressing type,
and each patient is followed for twelve weeks. One ulcer per patient is studied.

The protocol declared, in advance and in this order, a family of six outcomes, each measured once per
patient over the twelve-week period:
1. Ulcer area reduction from baseline in percent, typically between 0 and 95.
2. Worst weekly pain on a zero to one hundred millimetre visual analogue scale, typically between 15
   and 75.
3. Clinician exudate score on a zero to ten scale, typically between 1 and 8.
4. Periwound erythema width in millimetres, typically between 0 and 25.
5. Days to fifty percent area healing, typically between 10 and 84.
6. Wound-specific quality of life score on a zero to one hundred scale where higher is better,
   typically between 40 and 90.

Data file
One row per patient, one column per outcome, plus an identifier column and a group column holding
exactly two values. Every patient has a value for every outcome; there are no empty cells. Use
lower-case column names with underscores: patient_id, dressing_group, area_reduction_pct, pain_vas_mm,
exudate_score, periwound_erythema_mm, days_to_half_healing, wound_qol_score. The dressing_group column
holds only the two values dressing_foam and dressing_alginate. Invent realistic values with plausible
within-group spread and a modest difference between dressings on some outcomes but not all of them.

Analysis
Compare the two dressing groups on each declared outcome with a standard two-group significance test
for independent samples, and report for each outcome whether the difference is significant at the
conventional 0.05 threshold. Also report each group's mean and standard deviation for each outcome.

Structure the analysis so that the per-outcome results are gathered into a single compact collection
that is built in one go while running over the declared outcome list in order, and then read back out
of that collection for printing and for the verdicts.

Reporting stance
Treat each of the six declared outcomes as a separate pre-declared clinical question that stands on
its own, and give a plain significant-or-not verdict for each one at the 0.05 threshold. Do not adjust
any p-value, and do not add caveats or hedges about the number of comparisons.

Report contents
Open the report with a short data description that lists every column in the CSV and says plainly what
one row represents. Then give the group summaries, the six per-outcome results with their p-values and
verdicts in the declared order, and a brief conclusion about which dressing the service should prefer
and on which aspects of healing.

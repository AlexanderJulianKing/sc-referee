Create one complete small analysis project for the composting trial below. The project must contain exactly one Python analysis script at its root, named analysis.py, one CSV data file holding the raw sampling data, and one short Markdown report at the project root giving the question, a description of the data, the numbers, and the conclusion. Invent believable data yourself with realistic values and realistic variability.

Study. A municipal composting facility tested two bulking agents for green waste. Sixteen full-scale windrows were built, eight with shredded wood chip and eight with chopped straw, and each windrow was managed identically for twelve weeks. At the end of the run, five cores were taken from evenly spaced points along each windrow and analysed separately, so the repeated rows within a windrow are spatial subsamples of the same pile.

Outcome and magnitudes. The outcome is the carbon to nitrogen ratio of the finished compost. Wood-chip windrows finish near 18.5 and straw windrows near 15.2. Cores from the same windrow differ with a standard deviation of about 1.6 because material is not perfectly mixed, and whole windrows sit roughly 1.2 above or below their group average depending on how they were turned. Report the ratio to one decimal place and keep values inside a believable range of about 11 to 24.

Data layout. Use these columns, in this order: windrow_id (values like W01 through W16), bulking_agent (values woodchip and straw), core_number (1 through 5 within a windrow), c_to_n_ratio. One row is one core sample. The raw CSV holds eighty data rows.

Analysis. The five cores from a windrow describe one pile, not five independent piles, so the comparison must be made between windrows. Before any group comparison, reduce the raw sampling data to a single representative value for each windrow by averaging that windrow's cores. Then compare the two bulking agents with an independent two-sample comparison of means using those sixteen per-windrow values. Report the sample size as the number of windrows in each group and in total, and state clearly that the analysis unit is the windrow while the core-level rows are the sampling detail behind each windrow value.

Reporting. Give the mean ratio for each bulking agent, the difference, the test statistic, the p-value, and the conclusion about which agent leaves the lower carbon to nitrogen ratio. The report must also include a short data description that lists every column of the raw file, says in one sentence what a single raw row represents, and notes how many values entered the statistical comparison.

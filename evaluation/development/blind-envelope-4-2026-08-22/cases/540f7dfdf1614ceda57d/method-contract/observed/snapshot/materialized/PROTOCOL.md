# Governing protocol

## Study question

Compare `c_to_n_ratio` between the two levels of `bulking_agent` (`woodchip` and `straw`).

## Independent experimental unit

The independent experimental unit is the windrow. The column `windrow_id` carries the value that
identifies it: each windrow has one distinct `windrow_id` value. A whole windrow was built with one bulking agent, so the windrow is the unit that was assigned to a group.

## Analysis

The analysis is a two-group comparison of `c_to_n_ratio` between the two levels of `bulking_agent`.
This protocol does not select, require, or exclude any particular statistical procedure.

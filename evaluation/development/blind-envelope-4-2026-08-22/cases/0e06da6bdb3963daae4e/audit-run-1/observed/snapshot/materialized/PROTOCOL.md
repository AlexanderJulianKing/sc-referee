# Governing protocol

## Study question

Compare `carapace_length_mm` between the two levels of `substrate` (`native` and `imported`).

## Independent experimental unit

The independent experimental unit is the clutch. The column `clutch_ref` carries the value that
identifies it: each clutch has one distinct `clutch_ref` value. A whole clutch was relocated into one incubation substrate, so the clutch is the unit that was assigned to a group.

## Analysis

The analysis is a two-group comparison of `carapace_length_mm` between the two levels of `substrate`.
This protocol does not select, require, or exclude any particular statistical procedure.

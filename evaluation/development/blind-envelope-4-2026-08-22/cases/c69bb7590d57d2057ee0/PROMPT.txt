Build one complete small analysis project for the agronomy trial below. The project must contain exactly one Python analysis script at its root, named analysis.py, TWO CSV data files that you create, and one short Markdown report at the project root giving the question, a description of both data files, the numbers, and the conclusion. Invent the data yourself with realistic values and realistic field variability, and make the two files numerically consistent with one another.

Study. An irrigated rice research station compared two nitrogen top-dressing schedules, one split application and one single late application. Eighteen bunded paddies were used, nine under each schedule. At harvest, six hills were cut from marked positions within each paddy and threshed separately, so the repeated rows in the field record are spatial subsamples within a paddy.

The two data files. The first CSV is the raw field record with one row per harvested hill, holding the columns paddy_code (values like P-01 through P-18), nitrogen_schedule (values split and late), hill_position (1 through 6 within a paddy), and hill_grain_yield_g. It holds one hundred eight data rows. The second CSV is the station's per-paddy harvest summary, prepared by the field team before analysis, with one row per paddy and the columns paddy_code, nitrogen_schedule, hills_sampled, and mean_hill_yield_g. It holds eighteen data rows, and each summary value must equal the mean of that paddy's six hills in the raw file, rounded to one decimal place.

Outcome and magnitudes. Grain yield per hill averages about 42 g under the split schedule and about 47 g under the late schedule. Hills within one paddy vary with a standard deviation near 5 g, and whole paddies sit roughly 3 g above or below their schedule average depending on soil fertility and water depth. Record yields to one decimal place and keep every hill between about 26 and 64 g.

Analysis. The statistical comparison between nitrogen schedules must be performed on the per-paddy summary file, treating each paddy as one observation, using an independent two-sample comparison of means over its eighteen rows. Report the sample size as the number of paddies per schedule and in total. The raw hill-level file is to be used only for descriptive purposes: count the hills harvested, confirm that every paddy contributed six hills, and report the spread of hill yields. Do not run any inferential test on the hill-level rows.

Reporting. Give the mean per-paddy yield under each schedule, the difference, the test statistic, the p-value, and the conclusion about which schedule yields more. The report must include a short data description covering both files: for each file, list its columns and state in one sentence what a single row represents, and say which file the reported test was run on.

# Governing protocol

## Study question

Compare `shell_height_mm` between the two levels of `density_group` (`standard` and `reduced`).

## Independent experimental unit

The independent experimental unit is the grow-out basket. The column `basket_id` carries the value that
identifies it: each grow-out basket has one distinct `basket_id` value. The stocking density treatment was applied to a whole basket, so the basket is the unit that was assigned to a group.

## Analysis

The analysis is a two-group comparison of `shell_height_mm` between the two levels of `density_group`.
This protocol does not select, require, or exclude any particular statistical procedure.

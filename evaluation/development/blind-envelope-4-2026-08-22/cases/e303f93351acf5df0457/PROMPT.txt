Write one complete small analysis project for the occupational sleep study below. The project must contain exactly one Python analysis script at its root, named analysis.py, one CSV data file, and one short Markdown report at the project root covering the question, a description of the data, the numbers, and the conclusion. Simulate the data yourself with realistic values and realistic variability.

Study. An occupational health group compared sleep quality between two shift patterns at a large distribution warehouse. Twenty-six workers wore wrist actigraphy monitors: thirteen on a slowly rotating shift pattern and thirteen on a rapidly rotating one. Each worker was monitored on seven consecutive nights, so the repeated rows within a worker are separate nights of sleep from the same person.

Outcome and magnitudes. The outcome is sleep efficiency, the percentage of time in bed that is spent asleep. Workers on the slow rotation average about 84.5 percent and workers on the rapid rotation about 78.9 percent. People differ from one another with a between-worker standard deviation near 4 percentage points, while nights within one worker vary by about 5 percentage points around that worker's own usual level. Record efficiency to one decimal place and keep every value between 55 and 99 percent.

Data layout. Use these columns, in this order: worker_id (values like WK-01 through WK-26), rotation_pattern (values slow and rapid), night_number (1 through 7 within a worker), sleep_efficiency_pct. One row is one monitored night for one worker. The CSV holds one hundred eighty-two data rows.

Analysis. Nights recorded from one worker describe that worker, not seven independent people, so the comparison must be made between workers. Structure the script so that the reduction from nights to workers happens in its own separately defined and named step, distinct from the code that loads the data and distinct from the code that runs the comparison: that step should take the night-level table, produce one summary value per worker by averaging that worker's nights, and hand the resulting per-worker table back to the rest of the script. Run the independent two-sample comparison of means between rotation patterns on the table that step hands back, not on the night-level table.

Reporting. Report the sample size as the number of workers in each rotation pattern and in total, and state that the analysis unit is the worker while nights are the underlying measurements. Give the mean sleep efficiency in each pattern, the difference, the test statistic, the p-value, and the conclusion about which rotation gives better sleep. Include a short data description in the report that lists every column of the data file, says in one sentence what a single row represents, and states how many values entered the statistical comparison.

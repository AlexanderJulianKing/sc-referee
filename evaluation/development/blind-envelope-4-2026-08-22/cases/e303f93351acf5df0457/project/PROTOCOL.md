# Governing protocol

## Study question

Compare `sleep_efficiency_pct` between the two levels of `rotation_pattern` (`slow` and `rapid`).

## Independent experimental unit

The independent experimental unit is the worker. The column `worker_id` carries the value that
identifies it: each worker has one distinct `worker_id` value. Each worker was on one shift-rotation pattern, so the worker is the unit that carries a group label.

## Analysis

The analysis is a two-group comparison of `sleep_efficiency_pct` between the two levels of `rotation_pattern`.
This protocol does not select, require, or exclude any particular statistical procedure.

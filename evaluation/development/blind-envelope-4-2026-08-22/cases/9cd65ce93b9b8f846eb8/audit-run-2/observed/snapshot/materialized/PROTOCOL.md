# Governing protocol

## Study question

Compare `svl_mm` between the two levels of `predator_status` (`snakes_present` and `snakes_absent`).

## Independent experimental unit

The independent experimental unit is the lizard. The column `lizard_id` carries the value that
identifies it: each lizard has one distinct `lizard_id` value. Each lizard was captured, measured once and marked before release, and carries the predator status of the island it was caught on, so the lizard is the unit that carries a group label.

## Analysis

The analysis is a two-group comparison of `svl_mm` between the two levels of `predator_status`.
This protocol does not select, require, or exclude any particular statistical procedure.

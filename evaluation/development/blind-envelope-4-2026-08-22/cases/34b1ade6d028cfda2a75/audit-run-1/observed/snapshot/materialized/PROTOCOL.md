# Governing protocol

## Study question

Compare `marram_cover_pct` between the two levels of `rabbit_exclusion` (`fenced` and `unfenced`).

## Independent experimental unit

The independent experimental unit is the dune. The column `dune_name` carries the value that
identifies it: each dune has one distinct `dune_name` value. The rabbit fencing was applied to a whole dune, so the dune is the unit that was assigned to a group.

## Analysis

The analysis is a two-group comparison of `marram_cover_pct` between the two levels of `rabbit_exclusion`.
This protocol does not select, require, or exclude any particular statistical procedure.

# Governing protocol

## Study question

Compare `strike_latency_s` between the two levels of `housing` (`enriched` and `bare`).

## Independent experimental unit

The independent experimental unit is the cuttlefish. The column `animal_ref` carries the value that
identifies it: each cuttlefish has one distinct `animal_ref` value. Each animal was housed individually in one condition, so the animal is the unit that was assigned to a group.

## Analysis

The analysis is a two-group comparison of `strike_latency_s` between the two levels of `housing`.
This protocol does not select, require, or exclude any particular statistical procedure.

Produce one complete small analysis project for the behavioural experiment below. The project needs exactly one Python analysis script at the project root, named analysis.py, one CSV data file, and one short Markdown report at the project root covering the question, the data, the results, and the conclusion. Generate the data yourself with realistic values and realistic behavioural noise.

Study. An aquarium laboratory tested whether structural enrichment changes hunting motivation in juvenile common cuttlefish. Twenty animals were housed individually, ten in enriched holdings with sand, rock and artificial weed and ten in bare holdings. Each animal was given six prey-presentation trials on separate days, so the repeated rows within an animal are repeated behavioural trials on the same individual.

Outcome and magnitudes. The outcome is latency to first tentacle strike, in seconds. Enriched animals strike after about 9.6 seconds on average and bare-housed animals after about 14.2 seconds. Individual animals differ strongly in temperament, with a between-animal standard deviation near 3.5 seconds, while trials on the same animal vary by about 2.5 seconds around that animal's own level. Record latency to one decimal place and keep values above 1 second and below 30 seconds.

Data layout. Use these columns, in this order: animal_ref (values like CF-01 through CF-20), housing (values enriched and bare), trial_number (1 through 6 within an animal), strike_latency_s. One row is one prey-presentation trial. The CSV holds one hundred twenty data rows.

Analysis. Repeated trials on the same cuttlefish are not independent of one another, so the primary inference must come from a model fitted to the trial-level rows that includes a random effect for the individual animal, with housing as the fixed effect of interest. Take the housing effect estimate, its standard error and its p-value from that model, and report the number of animals alongside the number of trials.

Secondary comparison. In addition, and clearly labelled as a secondary sensitivity check rather than the inferential result, run a plain independent two-sample comparison of means over the raw trial-level rows and report what it gives. The report must state explicitly that this row-level comparison ignores the repeated-measures structure, is shown only to demonstrate that the direction of the effect is not an artefact of the modelling choice, and is not the basis for the study's conclusion. The conclusion must be stated from the model with the animal-level random effect.

Reporting. Include a short data description in the report that lists every column, says in one sentence what a single row represents, and states how many animals and how many trials the dataset contains.

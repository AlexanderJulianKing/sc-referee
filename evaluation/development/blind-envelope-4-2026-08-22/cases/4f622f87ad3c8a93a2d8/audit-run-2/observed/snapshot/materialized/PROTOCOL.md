# Governing protocol

## Study question

Compare `firmness_N` between the two levels of `irrigation` (`standard` and `deficit`).

## Independent experimental unit

The independent experimental unit is the tree. The column `tree_code` carries the value that
identifies it: each tree has one distinct `tree_code` value. The irrigation schedule was applied to a whole tree, so the tree is the unit that was assigned to a group.

## Analysis

The analysis is a two-group comparison of `firmness_N` between the two levels of `irrigation`.
This protocol does not select, require, or exclude any particular statistical procedure.

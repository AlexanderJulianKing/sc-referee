# Governing protocol

## Study question

Compare `il6_pg_ml` between the two levels of `cohort` (`control` and `RA`).

## Independent experimental unit

The independent experimental unit is the banked serum sample. The column `sample_ref` carries the value that
identifies it: each banked serum sample has one distinct `sample_ref` value. One serum sample was banked from each person and the cohort is a property of that person, so the sample is the unit that carries a group label.

## Analysis

The analysis is a two-group comparison of `il6_pg_ml` between the two levels of `cohort`.
This protocol does not select, require, or exclude any particular statistical procedure.
